## 개정 3 변경 요약

- **(차단 1)** 검출된 동기 후보가 있는데 대응을 정하지 못한 마커는 Missing이 아니라 Ambiguous(unassigned_candidate)다. Missing은 마커의 범위 안에 검출된 동기 후보가 하나도 없을 때만 쓴다.
- **(차단 2)** 판정할 마커의 범위 안에서 c0보다 앞에 미해결 검출이 있으면 Normal을 주지 않는다. 미해결 검출은 다른 마커로 확정 설명되지 않는 검출이다.
- **(차단 3)** 예측 L 시각과 실측 L 시각을 모두 포함한 불확실성 구간으로 범위를 판정한다. 경계에 걸치면 보류(Ambiguous(boundary))한다. 출처 포함은 보수적으로 한다(구간이 조금이라도 창과 겹치면 포함).
- **(차단 4)** 기준 8을 8a(다른 마커 Normal 금지), 8b(자기 마커 Normal 금지), 8c(검출된 신호의 Missing 금지)로 나눴다.
- **(차단 5)** M3를 "구조적 비트 중첩"에서 **간섭 지수 기반 검증 영역**으로 다시 정의했다. 간섭 지수는 주입 정보와 템플릿 상관으로 계산하는 모형값이고, 정리가 아니다. 경계 칸을 미리 고정한다.
- **(차단 6)** 경로 종류(실제, 누화, 에코, 다른 마커)는 주입 메타데이터로 고정한다. 정답 W와 분석기 추정 W를 분리한다. 누화 경로의 Normal은 지연과 관계없이 잘못 확정이다.
- **(차단 7)** 모든 평가 마커의 허용 최종 상태표를 만들었다. 분석 오류·정렬 실패·L 실패를 포함한다. 6a 분모를 정의했고, 6c를 전체 부호 시험과 창 기준 시험으로 나눴다.
- **(차단 8)** 누화 창의 안전성을 실행 중 누화 일관성 검사와 누화 확장 구역 Z로 직접 다룬다. Z의 값은 리그 실측 뒤에 정한다.
- **(D1)** 2000ms 초과는 사전 정의된 미보장 범위다. 보장 범위 안전성 주장의 환경 가정을 명시했다. 미보장 범위의 오확정은 별도로 집계하고 보고한다.
- **(D2)** 최초 경로의 관측 가능성을 주입 조건으로 정의했다. 오확정 0 기준은 관측 가능 칸에 적용한다. 관측 불가 칸은 평가 집합에 남기고 별도 보고한다. 에너지 일관성 검사는 별도 실험 후보다.
- **(D3)** 1ms 지연 하한은 도입하지 않는다(별도 설계 후보로 유지).

| 분석기가 기준점 전제를 충족하지 못해도 평가 대상 유지 | 명확화 | 산출 요구 시험에서는 실패, 안전 거부 시험에서는 해당 거부 기준으로 평가한다 |

## 분석기·신호 변경 (설계 검증 대상, 구현 미승인)

### 기호

- 일정 마커 집합 𝒦: 생성기 일정의 모든 마커. L 검출 여부와 무관하다.
- 예측 L 시각 t̂_L(m): Exact 기준점의 최소제곱 정렬로 예측한 시각. 모든 m ∈ 𝒦에 정의된다.
- 실측 L 시각 t_L(m): 선택된 L 후보 시각. L_ok인 마커에만 있다.
- 정렬 불확실성 u: u = max(2, 기준점 잔차 최대 절댓값 + 1)샘플. 기준점 범위 밖으로 외삽하는 마커에는 u_ext를 쓴다. u_ext = u + |ppm 추정 불확실성| × 외삽 거리. 기준점 범위와 ppm 불확실성의 계산법은 구현에서 고정하고 테스트로 보호한다.
- L 기준 구간 T_L(k) = [min(t_L, t̂_L) − u, max(t_L, t̂_L) + u]. L_ok가 아니면 [t̂_L − u_ext, t̂_L + u_ext]다.
- 후보 c: R 채널 동기 후보 중 관문을 넘은 것. 시각은 t_c다.
- 관측 비트 b_c ∈ {0, 1, ⊥}^16. ⊥는 소거, E_c는 소거 위치 집합, e_c = |E_c|다.
- cw(m): 마커 m에 배치된 코드워드(A0 배치표)
- 비소거 비트 거리: δ_c(m) = |{ i ∉ E_c : b_c,i ≠ cw(m)_i }|
- 지연 구간 D_c(m) = t_c − T_L(m). 구간값이다.
- 실제 비트 오류 수 t: 소거되지 않은 위치에서 실제로 뒤집힌 비트 수. 시험에서만 주입값으로 안다.

### 지연 범위와 환경 가정 (D1)

| 구간 (d = R − L) | 이름 | 분석기 보장 |
|---|---|---|
| d < W_lo, d ∈ W 또는 W 확장 구역 Z | 음의 지연·누화 구역 | Normal 금지(U3) |
| W_hi + Z < d ≤ D_max | **보장 범위** | 기준 1a~7, 6a-wav 적용. D_max = 48000샘플(1000ms) |
| D_max < d ≤ D_src | **탐지·거부 범위** | 기준 1a, 8a·8b, K1b 적용. D_src = 96000샘플(2000ms) |
| d > D_src | **미보장 범위** | 탐지를 보장하지 않는다. 오확정은 기준 1c로 별도 집계·보고한다 |

- **미보장 범위의 한계(명시):** 미보장 범위의 신호는 보장 범위의 다른 마커로 잘못 확정될 수 있다. 개정 2 설계 검증의 실제 반례가 있다. 순번 36(ID16)의 신호가 240000샘플 늦게 도착하고 3비트 오류로 순번 45(ID130)로 정정되면, 500ms Normal로 확정된다. A0 거리 조건은 출처 창 안의 마커끼리만 보호한다.
- **보장 범위 안전성 주장의 환경 가정.** 아래 가정이 모두 성립할 때만, 보장 범위 마커의 Normal이 안전하다고 주장한다.
  - E1: 실제 리그의 모든 R 신호(실제 경로, 에코, 누화, 다른 마커 신호)의 지연 ≤ D_src
  - E2: 출처 창 안 마커 쌍에 대해 소거되지 않은 위치의 실제 비트 오류 t ≤ 6
  - E3: 정렬 오차 ≤ u(외삽은 u_ext)
  - E4: 최초 경로가 관측 가능하다(D2의 주입 정의). 실제 리그에서는 관측으로 확인할 수 없다.
  - E5: 누화 지연이 A_x = [W_lo, W_hi + Z] 안에 머문다. Z의 근거는 리그 자체 검증 실험 파일에 기록한다("누화 창 안전성" 2a)
- **가정의 실제 리그 점검 가능성:**
  - E5는 실행 중 누화 일관성 검사로 부분 점검한다. 누화 후보가 N개 미만이면 점검되지 않으며, 검사 통과가 E5 성립의 증거는 아니다.
  - E1은 부분적으로만 점검할 수 있다. 일정상 출처가 D_src 밖인 확신 ID가 검출되면 가정 위반을 탐지하고 실행 경고를 낸다. 오정정된 경우는 탐지할 수 없다.
  - E3은 정렬 잔차로, E5는 실행 중 누화 일관성 검사로 점검한다.
  - E2와 E4는 관측으로 확인할 수 없는 전제다.

### A0 ID 배치 변경 (신호 변경)

- **배치표:**
  - 마커 순번 i → 코드워드 인덱스 π(i)의 결정적 배치표를 쓴다. 현행은 π(i) = i다.
  - 알고리즘(고정): 미사용 코드워드 인덱스를 오름차순으로 탐색해, 직전 5개 순번의 코드워드와 모두 거리 ≥ 8인 첫 인덱스를 고르고 반복한다.
  - [사실, 리뷰어 계산과 설계 검증에서 독립 재현] 길이는 1,704이고 시작은 `0, 15, 113, 126, 402, 413, 160, 7, 73, 118, 314, 405`다. 연속 6개 모든 쌍에 대해 전수 위반 0이다. 1,704가 가능한 최대 길이라는 증명은 아니다.
- **창 안 최대 마커 수:**
  - 등간격 예측 일정에서 반개구간 출처 창의 폭 B = D_src − W_hi와 마커 간격 s에 대해, 창 안 최대 마커 수는 ⌈B / s⌉다.
  - 정렬 기울기가 ±100ppm으로 제한되면 최대 5개다(−100ppm에서 5개, 0과 +100ppm에서 4개).
  - 연속 6개 조건은 정렬 기울기 |ppm| ≤ 100을 전제로 충분하다. |ppm 추정| > 100이면 지원 범위 밖으로 보고, 실행을 측정 불가로 처리한다(경고가 아니라 거부).
  - 마커 수 상한은 출처 포함을 보장하지 않는다. 출처 포함은 아래 A1의 불확실성 구간 규칙으로 다룬다.
- **지원 최대 마커 수:** 배치표 길이 1,704. ID는 재사용하지 않고 순환하지 않는다. 초과 설정은 거부한다. `MAX_MARKERS`(일정 길이 상한)와 2048개 부호 공간의 인코딩·복호 범위를 분리한다.
- **거리 조건 안에서만 성립하는 주장:**
  - 출처 창 안 다른 마커와의 거리가 8 이상이면, δ(m) ≥ 8 − e − t다(음수면 0).
  - 다른 마커 ID로의 오확신에는 t ≥ 8 − e − τ가 필요하다. Exact는 8, Corrected는 7, ErasureCorrected는 7이다.
  - 다른 마커가 가능 대응(δ ≤ 3)이 되려면 t ≥ 5 − e가 필요하다.
  - 따라서 소거 0개·실제 오류 1개 후보는 창 안 다른 마커와 모호해지지 않는다. "1비트 손실 0%"는 이 조건 안의 주장이다.
  - 이 하한은 **다른 마커 ID로의 오확신**에 대한 것이다. 같은 ID 에코를 최초 경로로 잘못 고르는 것은 막지 않는다.
  - 소거가 늘면 보호가 줄어든다. 예: cw(0)과 cw(15)는 거리 8이지만, 비트 0~3을 소거하고 비트 4를 뒤집으면 두 마커 모두 가능 대응이다.
- **검증 항목(구현 테스트):** 배치표 해시·전수 거리 검사, 지원 최대 마커 수 초과 거부, ID 비순환을 확인한다. 정렬 오차를 포함한 창 경계·일정 시작과 끝에서 M_c 구성을 전수 확인한다. 소거 확대에 따른 대응 확산을 측정한다.
- **기록:** 채택되면 신호 변경으로 `DESIGN.md`·`DISCUSSION-LOG.md`에 남긴다. 생성 WAV 해시가 바뀐다.

### A3 소거 복호의 오류·소거 예산

- 소거 e개를 뺀 펑처드 부호의 최소 거리는, e = 0~3의 모든 소거 위치에서 정확히 4 − e다(개정 1·2 설계 검증에서 증명·전수 계산).
- 정책 (e, τ)에서 오답 확정에 필요한 최소 실제 오류 수는 t_min = 4 − e − τ다(전체 부호 기준).

| 정책 (소거 e, 허용 거리 τ) | 유일 복호 2τ + e < 4 | t_min (전체 부호) | 채택 |
|---|---|---|---|
| (0, 0) Exact | 예 | 4 | 예 |
| (0, 1) Corrected | 예 | 3 | 예 (현행) |
| (1, 0) ErasureCorrected | 예 | 3 | **예 (신규)** |
| (1, 1) | 예 | 2 | 아니요 |
| (2, 0) | 예 | 2 | 아니요 |
| (3, 0) | 예 | 1 | 아니요 |

- **ID 확정 성공:** (e = 0 ∧ min δ ≤ 1) 또는 (e = 1 ∧ min δ = 0). 최소 거리 탐색은 2048개 전체 코드워드에서 한다. 결과가 배치표에 없으면 확정 실패(일정 밖 ID) 진단이다.
- **ID 확정 거부:** 그 밖의 모든 경우. e ≥ 2이면 항상 거부한다. 거부된 관측은 A1의 가능 대응 계산에만 쓴다.
- 확신 ID의 안전성은 이 예산과 A0 거리로만 보장한다. A1은 독립 확인 수단이 아니다.

### A1 출처 일관성 매칭

- **출처 집합:** M_c = { m ∈ 𝒦 : D_c(m) ∩ (W_hi + Z, D_src] ≠ ∅ }. 구간이 조금이라도 겹치면 포함하는 보수적 포함이다. L_ok로 제한하지 않는다.
- **출처 집합 거리 검사(개정 4, 결정 4):** dist_ok(c) ⟺ M_c 안의 서로 다른 모든 마커 쌍 (m, m')에 대해 d(cw(m), cw(m')) ≥ 8. 후보 수(\|M_c\| ≤ 5 등)로 대신하지 않고 쌍마다 직접 계산한다. 불확실성 구간 때문에 M_c가 연속 6개를 넘으면 A0 보장 밖이다(예: 순번 0과 6은 거리 4). 이 검사가 그 경우를 잡는다.
- **확신 대응:** confident(c, m) ⟺ m ∈ M_c ∧ dist_ok(c) ∧ A3 ID 확정 성공 결과가 cw(m). dist_ok(c)가 거짓이면 c는 어떤 마커로도 확신 대응하지 않는다(확신 확정 거부). 따라서 c는 다른 마커를 확정 설명하지 못하고 미해결 후보로 남는다.
- **가능 대응:** possible(c, m) ⟺ m ∈ M_c ∧ δ_c(m) ≤ T_p, T_p = 3(설계 후보). confident ⟹ possible.
- S_c = { m : possible(c, m) }
- **확정 설명:** 후보 c가 "마커 m으로 확정 설명된다" ⟺ confident(c, m) ∧ S_c = {m}
- **마커 k의 범위:** R_k = { c : t_c − T_L(k) ∩ (W_lo, D_src] ≠ ∅ }. 누화 구역부터 탐지·거부 범위 끝까지 검출된 모든 후보다.

**마커 k의 판정 (위에서부터 첫 번째로 해당하는 줄이 결정, 단일 순서):**

| 순서 | 조건 | 결과 |
|---|---|---|
| 0 | 분석 오류 또는 정렬 실패 | 실행 전체 "판정 불가". 평가에서는 아래 허용 상태표의 "분석 오류" 행으로 센다 |
| 1 | k가 L_ok가 아님 | R 분류 없음(L 분류로 보고). k는 출처 후보로는 계속 남는다 |
| 2 | L 선택이 유일하지 않음: 같은 ID의 L 후보가 둘 이상이고 그 시각들이 u 밖으로 다름. 중복 제거 **후** 후보 기준이며, 2샘플은 후보 동일성 허용치이지 경로 분해 한계가 아니다 | Ambiguous(l_ambiguous) |
| 3 | R_k가 비어 있음 | **Missing**(no_candidate). 검출 근거가 전혀 없는 경우만 |
| 4 | R_k 중 다른 마커로 확정 설명되지 않는 후보를 미해결 후보로 둔다(k 확정 설명 후보 포함). 미해결 후보가 없음(전부 다른 마커로 확정 설명됨) | 일정 모순이 있으면 IdMismatch, 아니면 Missing(explained_elsewhere)·진단 보존. 이 경우 k의 신호는 검출되지 않은 것이다 |
| 5 | 미해결 후보 중 가장 이른 후보를 c0으로 둔다. 서로 다른 후보가 2샘플 안에서 동률 | Ambiguous(tie) |
| 6 | D_c0(k)의 일부라도 누화 구역(W 또는 Z)에 걸침 | Ambiguous(xtalk_like / abnormal_near / boundary) |
| 7a | dist_ok(c0)가 거짓 | Ambiguous(source_set_distance). 사유와 위반 쌍을 기록한다 |
| 7 | c0이 k로 확정 설명되지 않음 | k ∈ S_c0이고 S_c0 = {k}면 IdUndecodable, k ∈ S_c0이고 \|S_c0\| ≥ 2면 Ambiguous(correspondence), k ∉ S_c0면 Ambiguous(unassigned_candidate) |
| 8 | c0이 k로 확정 설명되지만 D_c0(k) ⊄ (W_hi + Z, D_max] (구간이 경계에 걸치거나 D_max를 넘음) | Ambiguous(boundary 또는 out_of_support). 개정 3의 문구는 포함 방향이 뒤집혀 있었다(결정 6) |
| 9 | 그 밖 | **Normal**. 지연 = t_c0 − t_L(k)(실측 L 기준) |

- 4~7단계의 뜻: c0보다 앞에 미해결 검출이 있으면, 그 검출이 k의 최초 경로일 가능성을 배제할 수 없으므로 Normal을 주지 않는다(차단 2). k로 확정 설명되는 후보만 있을 때도 가장 이른 것만 쓴다.
- 중복 배정:
  - 후보 하나는 확정 설명되는 마커 하나의 Normal·IdUndecodable 근거만 된다.
  - 미해결 후보는 여러 마커의 Ambiguous 근거가 될 수 있다.
  - R_duplicate는 Normal 마커의 c0 뒤에 오는, k로 확정 설명되는 후보만 센다. 그 밖의 공유 후보는 R_shared로 센다.
- 실행 전체 지연 중앙값은 어떤 판정에도 쓰지 않는다. 현행 `analyze.rs`의 `dhat` 기반 판정은 구현에서 모두 제거하고, 제거 여부를 리뷰에서 확인한다.
- **차단 원인별 보고(필수):**
  - 자기 최초 경로의 ID 불확실 때문에 막힌 수
  - 다른 마커·누화 후보 때문에 막힌 수
  - 뒤에 정답 확정 후보가 있었지만 앞선 미해결 후보로 막힌 수
  - 경계 보류 수
  - 깨끗한 마커가 다른 마커의 손상만으로 막힌 수(독립 칸, G10)
  - 삭제 마커로 번진 Ambiguous 수
- **T_p = 3의 비용 [사실, A0 없음]:** 순차 ID(π(i) = i)에서는 소거 0개·1비트 오류 후보의 21.875%(ID 0..599)가 Ambiguous가 된다. A0을 적용하면 A0 거리 조건 안에서 0%다.

### A2 임시 방어책 (비교용, 채택 대상 아님)

같은 ID 후보가 지연이 다르게 둘 이상이면 그 마커를 전부 Ambiguous로 한다. A1과 같은 하네스로 돌려, 정상 다중 경로 칸에서 측정 가능률이 얼마나 떨어지는지 비교 보고한다.

### A4 비트 존재 관문 결합

- 비트 존재 판정만, q와 진폭이 같은 위치·같은 템플릿에서 함께 관문을 넘도록 바꾼다. peaks와 6 dB 마진은 바꾸지 않는다.

- A4는 ID 복원 개선책이 아니다.
- 진단은 두 가지로 나눠 보고한다.
  - 비트 관문 변화: 거짓 비소거 제거 수
  - 전체 재분석 결과의 변화

### A5' 에너지 일관성 검사 (별도 실험 후보, 실험 002 본실행에 넣지 않음)

### 누화 창 안전성 (차단 8)

- 교정 W만으로는 실행 중 누화 지연 이동을 막지 못한다. 교정 산포가 0이면 W는 ±2이고, 3샘플로 이동한 누화가 Normal이 될 수 있다. 1ms 하한(D3)은 도입하지 않고, 다음으로 직접 다룬다.
  1. **누화 확장 구역 Z:** W 위쪽 (W_hi, W_hi + Z]의 후보는 Normal이 되지 않는다(A1 6단계). Z의 값은 `___`다. 리그 자체 검증에서 측정한 누화 지연의 세션 간·세션 내 변동 폭과, 실제 유효 경로의 최소 지연 관측을 독립적으로 검증한 뒤 정한다. 그 전에는 측정 모드 analyze를 거부한다. 합성 검증에서는 주입한 변동 폭으로 Z를 준다.
  2. **실행 중 누화 일관성 검사(개정 5, 결정 3):**
     - 구간 표기: W = [W_lo, W_hi](양 끝 포함), Z = (W_hi, W_hi + Z](위쪽만, 대칭 아님). 허용 구간 A_x = [W_lo, W_hi + Z].
     - 누화 후보: dist_ok이고 마커 k로 확신 대응하며, 지연이 탐색 구간 (W_lo − X, W_hi + Z + X] 안인 R 후보다. X는 탐색 여유다. 실제 리그에서는 Z와 같은 리그 자체 검증으로 정하고, 실제 유효 경로의 최소 지연보다 작아야 한다(`___`). 합성 검증에서는 칸 정의에서 실행 전에 고정한다.
     - 판정: 누화 후보 수 ≥ N이고 그중 하나라도 A_x 밖이면, 그 실행은 "교정 불일치"로 거부(측정 불가)한다. 누화 후보 수 < N이면 검사가 성립하지 않았음을 기록하고 거부하지 않는다(E5 미점검 경고). N은 일관성 검사의 최소 표본 수다. **합성 검증에서는 N = 10**(사용자 결정, 합성 검증용 후보값으로 고정). 실제 리그에서 N = 10이 충분한지는 리그 자체 검증에서 별도로 검증한다.
     - 개정 4의 "교정 W 이탈"보다 실행 허용 범위가 넓다. A_x 안이면 거부하지 않으며, Z 안의 후보는 A1 6단계와 U3로 Normal이 되지 않는다.
     - 재교정 뒤 다시 측정한다.
  2a. **Z 근거의 기록 위치(E5와 연결):** Z와 X의 값과 근거(누화 지연의 세션 간·세션 내 변동 폭, 반복 측정 표본 수, 실제 유효 경로 최소 지연의 독립 검증)는 리그 자체 검증 실험 파일(`docs/experiments/NNN-…`, 번호는 생성 시 부여)의 결과 절에 적는다. 원본은 `.local/`에 둔다. 이 문서의 E5와 Z 빈칸에는 그 파일 경로를 적는다. 그 기록이 없으면 측정 모드 analyze를 거부한다. Z는 리그 실측 근거로만 정한다.
  3. Z 안의 실제 경로는 Normal이 되지 않는다. 그런 리그 구성은 지원 범위 밖으로 보고한다. 리그 측정에서 실제 경로의 최소 지연이 Z와 겹치면 측정 불가다.
- 이 규칙은 누화 오확정을 하한 뒤로 숨기는 것이 아니다. Z의 근거, 실행 중 일관성 검사, 그리고 Z와 실제 경로 지연의 분리를 각각 검증하는 구조다.

## 고정 평가 집합

실험 시작 전에 칸 목록과 시드를 고정한다. 결과를 보고 칸을 빼거나 더하지 않는다. 칸마다 마커 20개 이상, 실제 경로 마커는 합계 20,000개 이상이다. 하네스의 녹음 길이는 주입한 최대 경로 지연으로 정한다.

- **G1~G5, G5-risk:** 실험 001의 칸 정의와 시드(회귀)
- **G2-int:** 누화와 실제 경로의 간섭 지수 경계
  - 비트 정렬 오차 s ∈ {0, 4, 8, 10, 12, 16, 24, 48, 96, 240}샘플. 지연 차이 Δ = 960 + s와 4800 + s, 그리고 반 슬롯 1200, 5040
  - 상대 레벨: 실제 − 누화 ∈ {−6, −3, 0, +3, +6, +10, +20} dB
  - 극성 4조합
- **G3-normal:** 에코가 최초 경로보다 약한 정상 다중 경로. 상대 −3 / −6 / −10 dB, 간격 2 / 5 / 10 / 20 / 50ms
- **G3-hidden:** 관측 불가능한 최초 경로 칸. 실험 001 G3의 강한 에코 칸과, 관문 아래 최초 경로 + 깨끗한 뒤 에코 칸
- **G6 혼합 손상:**
  - 주입 오류 마스크 F와 소거 마스크 E의 조합 (|E|, |F|) ∈ {0..4} × {0..4}
  - L 해독 실패와 결합하고, 지연 20 / 600 / 900ms에서 시험한다.
- **G7 범위 밖 지연:**
  - 탐지·거부 범위: 1100 / 1500 / 1900ms
  - 미보장 범위: 2100 / 2500 / 5000ms. 개정 2 설계 검증의 순번 36→45 반례를 포함한다.
  - 각각 비트 오류 0~6개와 결합한다.
- **G7-edge (경계 안전성 시험, 결정 4):**
  - W_hi + Z, D_max, D_src 각각의 −1 / −0.5 / 0 / +0.5 / +1샘플
  - 정렬 오차 양극성 (±u_inj)
  - 음의 지연(d < W_lo)
  - 보장 범위 쪽 칸의 마커는 edge 플래그를 갖고 기준 2·6a-wav 분모에서 빠진다. 의무는 U5, 1a, K1·K2, U1~U4다.
- **G8 누화 창(결정 2·3):** 교정 W 경계 ±1샘플의 누화, Z 안팎의 누화, 실행 중 누화 지연 이동.
  - 실제 경로가 있는 마커는 U2와 일반 기준으로 평가한다(G8이라는 이유로 Normal을 금지하지 않는다).
  - **칸 지정(주입 누화 이동량으로 사전 지정):** 실행 중 누화 지연 = 교정 누화 지연 + 주입 이동량이다.
    - 이동 후 누화 지연이 A_x 안 → **사전 유효 칸**(cellX = valid)
    - A_x 밖이고 탐색 구간 안이며, 관측 가능 누화 마커 ≥ N → **관측 가능 불일치 칸**(cellX = obs_mis)
    - A_x 밖이고, 관측 가능 누화 마커 < N이거나 탐색 구간 밖 → **관측 불가 불일치 칸**(cellX = unobs_mis)
  - **누화 관측 가능 조건(주입, 최초 경로 조건과 별개, 검출 결과로 정하지 않음):** (x1) 누화 주입 피크 레벨 ≥ abs_floor_dbfs, (x2) 누화 기준 SNR ≥ 10 dB이거나 잡음 없음, (x3) 누화 경로와 다른 모든 경로의 시작 간격 ≥ 2 × dedup_radius(96샘플). 세 조건을 모두 만족하는 누화 경로가 있는 마커가 "관측 가능 누화 마커"다.

## 분모

- **주입 마커:** 하네스가 생성한 모든 마커. 분석기 출력과 무관하게 하네스가 센다.
- **평가 대상 마커:** 주입 마커 중 "평가 규약"의 "평가 대상 포함" 규칙(기준 시각이 녹음 안)을 만족하는 마커. 분석 오류·정렬 실패·L_ok 아님·실행 거부는 빼지 않는다.
- **관측 가능 최초 경로 마커(D2):** 평가 대상 중 아래 "관측 가능 조건"을 만족하는 마커
- **지연 산출 요구 대상(개정 5):** "평가 규약"의 B7 ∧ ¬M2 ∧ ¬M3 ∧ ¬safe ∧ ¬edge. B7은 실제 경로 있음, zone = 보장, obs, L 주입 손상 없음, 교정 불일치 지정 칸 아님, 의도된 거부 칸 아님이다.
- **안전한 실패 분류 대상:** 주입 손상 (|E|, |F|) ∉ {(0, 0), (0, 1), (1, 0)}, 또는 비트 전부 무음
- **6a-dec 대상(고정 비트 입력, WAV 없음):** 2048개 코드워드 전부 × 손상 (0, 0) 1가지 + (0, 1) 오류 위치 16가지 + (1, 0) 소거 위치 16가지 = 67,584 입력. A3 복호기에 비트 관측을 직접 넣는다.
- **6a-wav 대상(주입 조건만으로 결정, 분석기 출력과 무관):** 평가 대상 중 다음을 모두 만족하는 마커다.
  1. 주입 손상 (|E|, |F|) ∈ {(0, 0), (0, 1), (1, 0)}
  2. 관측 가능 조건 1~4 충족
  3. 정답 지연 d가 보장 범위 안이고, d − u_inj > W_hi^truth + Z, d + u_inj ≤ D_max (¬edge. u_inj는 아래 정의). 분석기가 계산한 u가 u_inj보다 커서 보류되면 실패로 센다.
  4. M3가 아님(주입 정보로 계산)
  5. L 쪽 주입 손상(L 비트 손상, L 삭제, L crop)이 없음
  6. 교정 불일치 지정 칸·의도된 거부 칸이 아님. 개정 5에서 6a-wav 대상은 지연 산출 요구 대상과 같은 집합이다.
- **u_inj: 주입 정보로 계산한 최소제곱 예측 오차 상한(결정 5):**
  - 대상은 주입 ppm 값 자체가 아니라 **기울기·절편 추정 오차가 만드는 L 시각 예측 오차**다. 참 ppm과 오프셋은 선형 모형 t_L = a + b·t에 정확히 흡수된다.
  - 기준점 집합 A_inj(칸): 칸의 마커 중 L 주입 손상이 없고, L 경로 주입 피크 레벨 ≥ abs_floor_dbfs이고, L 기준 SNR ≥ 10 dB이거나 잡음이 없고, L 마커 전체가 녹음 안인 마커 **전체**다. 분석기 기준점 선택 규칙(Exact ID L 후보, 최소 개수·시간 범위, 잔차 제거)과 같은 조건을 주입으로 표현한 것이다.
  - 입력: A_inj의 실제 기준점 시각 t_i(일정과 주입 ppm으로 계산), 주입 L 타이밍 교란 상한 ε_inj, 검출 시각 오차 가정값 ε_det = 0.5샘플. ε = ε_inj + ε_det.
  - **전제(검증 대상, 증명 아님):** "분석기가 얻는 기준점별 L 타이밍 오차 |ê_i| ≤ ε"는 증명된 사실이 아니라 하네스가 검증할 전제다. 기준 5b의 합격선(0.5샘플)은 이 상한의 근거로 쓰지 않는다. 5b는 마커 후보 시각 정확도 기준이고, 기준점 타이밍 오차의 상한을 보장하지 않는다.
  - 최소제곱 예측의 가중치는 h_i(t) = 1/n + (t − t̄)(t_i − t̄) / Σ_j (t_j − t̄)²다. |e_i| ≤ ε인 모든 교란에 대해 예측 오차는 ε · Σ_i |h_i(t)| 이하이고, 이 값은 최악 교란에서 달성된다. 기준점 범위 밖 외삽은 (t − t̄) 항이 키운다.
  - u_inj(칸) = 2 + max_{k ∈ 칸} ε · Σ_i |h_i(t_L,k)|. 칸별 상수로 실행 전에 고정하고 표로 보고한다.
  - **성질 u_inj ≥ 2(식의 성질, 전제와 무관):** Σ_i h_i(t) = 1이므로 Σ_i |h_i(t)| ≥ 1 > 0이고, ε ≥ 0이므로 모든 칸에서 u_inj = 2 + ε · Σ|h_i| ≥ 2다. □ 이 성질은 u_inj가 실제 예측 오차의 상한이라는 뜻이 아니다. 상한이라는 해석은 위 전제가 성립할 때만 유효하다.
  - **ε 초과 처리:** 하네스는 칸마다 기준점별 실제 타이밍 오차(분석기가 얻은 L 기준점 시각 − 주입 L 시각)를 측정해 ε와 비교한다.
    - 하나라도 ε를 넘으면 그 칸의 u_inj 전제를 **"미검증"**으로 표시한다.
    - 미검증 칸에서는 edge 지정과 경계 판정(U5, 6a-wav의 경계 제외)에 대해 검증 통과를 주장하지 않는다. 보고서에 "u_inj 전제 미검증"으로 함께 적는다.
    - 해당 마커는 분모에서 빼지 않고 원래 플래그대로 그대로 판정한다(edge 지정은 실행 전에 고정한 값을 유지한다).
    - 미검증 칸 수, 칸별 최대 타이밍 오차와 ε를 보고한다.
  - 전제: |A_inj| ≥ 3이고 기준점 시각이 서로 다르며, ε가 분석기 잔차 제거 문턱(interval/4)보다 충분히 작다. |A_inj| < 3인 칸은 "기준점 부족 주입 칸"으로 의도된 거부 칸(cellR)이다.
  - **분석기가 기준점 전제를 충족하지 못한 경우**(다른 기준점을 고름, 잔차 제거, 정렬 실패, u > u_inj): 평가 대상에서 빼지 않는다. 지연·ID 산출을 요구하는 시험(2, 6a-wav)에서는 실패로 센다. 안전한 거부를 요구하는 시험(L 삭제, 정렬 실패 주입, 기준점 부족 주입 등)에서는 해당 거부 기준(R4)으로 평가한다.
- **6a-wav에서 M2는 생기지 않는다(증명):**
  - 6a-wav 대상은 보장 범위 안이고, 고정 평가 집합의 |ppm| ≤ 100이다. 그래서 M^truth(k)는 연속한 일정 순번 최대 5개다(A0 "창 안 최대 마커 수").
  - A0 배치표에서 연속 6개 순번 안의 모든 쌍은 거리 ≥ 8이다. 따라서 m ∈ M^truth(k), m ≠ k이면 d(cw(k), cw(m)) ≥ 8이다.
  - 두 코드워드가 다른 위치 중 소거되지 않은 곳은 8 − |E|개 이상이다. 그중 주입 오류로 b^inj가 cw(k)와 달라진 곳은 |F|개 이하다. 나머지에서는 b^inj = cw(k) ≠ cw(m)이다.
  - 그러므로 δ^inj(m) ≥ 8 − |E| − |F| ≥ 7 > 3 = T_p이고, M2 조건 ∃ m ≠ k : δ^inj(m) ≤ 3은 거짓이다. □
  - 이 증명은 주입 시각 기준의 M^truth에 대한 것이다. 분석기의 M_c는 불확실성 구간 때문에 더 넓을 수 있고, 그 경우는 dist_ok 검사(A1)가 다룬다.
- **6a-wav 판정:** 대상 마커마다 정답 ID로 A3 확정 성공이고 그 후보가 정답 경로이면 성공이다. 동기 미검출, 분석 오류, 정렬 실패, 확정 거부, 오답 ID, 정답 ID가 비정답 경로 후보에서 나온 경우는 모두 실패다.
- **보조 지표(판정 아님):** 검출 조건부 ID 복원률 = 정답 ID 확정 수 / (진짜 동기 후보가 검출된 6a-wav 대상). 동기 미검출 수와 함께 보고한다.
- 보고 비율. 전체·그룹·칸별로 내며, 모호함 허용·관측 불가·미보장 칸도 전체 평가 집합 기준 비율에 계속 포함한다.

  - 놓침 / 지연 산출 요구 대상
  - Normal / 평가 대상
  - L_ok / 평가 대상
  - Normal / L_ok
  - Ambiguous / 평가 대상(사유별)

## 정답 경로

- **경로 종류는 주입 메타데이터로 고정한다:** 실제(최초·후속), 누화, 에코, 다른 마커 신호. 분석기의 교정 W나 출력으로 종류를 바꾸지 않는다.
- **정답 W와 추정 W:** 정답 W는 주입한 누화 지연 범위다. 분석기는 교정 추정 W를 쓴다. 두 값을 구분해 기록한다.
- **최초 경로:** 주입한 실제 경로 중 가장 이른 것
- **정답 지연:** 최초 경로의 주입 R−L 시간차(원시, 주입 오프셋과 ppm 포함)
- **잘못 확정:** 최종 분류가 Normal인데 다음 중 하나에 해당한다.
  - 선택된 후보가 최초 경로가 아니다(누화·에코·다른 마커 신호. 누화는 지연과 무관하게 잘못 확정이다).
  - 지연이 정답 지연과 허용치 넘게 다르다.
- **시각 허용치(주입 기준):** 다른 경로가 ±marker_len 안에 있으면 2샘플, 아니면 0.5샘플이다. ppm 칸은 기준 5b를 따른다. 분석기 overlap 표시는 쓰지 않는다.
- **관측 가능 조건(D2, 주입 정의, 분석기 출력과 무관):** 다음을 모두 만족하면 최초 경로가 관측 가능하다.
  1. 최초 경로의 주입 피크 레벨이 abs_floor_dbfs(−60 dBFS, 검출기 절대 진폭 관문) 이상이다. 개정 4의 +10 dB 여유는 없앴다(결정 6, 강화). 관문 위 10 dB 대역은 "조건 1 경계 대역 칸"으로 따로 목록화한다.
  2. SNR ≥ 10 dB이거나 잡음이 없다.
  3. ±marker_len 안에 최초 경로보다 주입 레벨이 높은 다른 경로가 없다(M1이 아님). "다른 경로"는 누화(앞선 누화 포함), 에코, 다른 마커 신호 전부이고 방향(앞·뒤) 조건이 없다(결정 3). 누화 때문에 이 조건을 어긴 칸·마커 수와 M3 중복은 결과 보고에 따로 적는다.
  4. 다른 모든 경로와의 시작 간격이 2 × dedup_radius(96샘플) 이상이다.
  - 이 정의는 "현 검출기가 원리상 분리할 수 있어야 할 조건"을 주입으로 정한 것이다. 관측 불가 칸에서 최초 경로가 실제로 검출될 수도 있다. 관측 가능 칸에서 검출되지 않으면 실패다.

## 모호함 허용 조건 (주입 조건으로 사전 정의)

아래 조건의 마커는 지연 산출 요구 대상에서 빠진다(놓침 판정 안 함). 평가 집합에는 남고, 관측 가능 칸이면 잘못 확정은 0이어야 한다.

- **(M1) 관측 불가 최초 경로:** 위 관측 가능 조건 3을 어긴다. 자기 신호의 최초 경로 오확정만 기준 1b로 별도 집계한다. 유지 의무 U1~U4와 일관성 검사 K1·K2는 그대로 적용한다("평가 규약").
- **(M2) 주입 비트 손상의 대응 모호:**
  - 주입 오류 마스크 F와 소거 마스크 E로 예상 관측 b^inj를 만든다. 다음을 만족하면 M2다.

    ∃ m ≠ k : m ∈ M^truth(k) ∧ δ^inj(m) ≤ 3

  - M^truth(k)는 주입 시각과 전체 일정으로 계산한 출처 창의 마커 집합이다.
  - 누화·에코 혼합으로 생긴 소거에는 적용하지 않는다.
- **(M3) 간섭 지수 영역(검증할 모형, 정리 아님):**
  - 실제 경로의 각 비트 k와 다른 경로(누화·에코·다른 마커 신호)의 각 비트 j에 대해 정렬 오차 s_kj를 구한다. 기준은 주입 시작 시각과 비트 슬롯 위치다.
  - 간섭 지수: I_kj = (g_other / g_real) × max_{|δ| ≤ 2} ρ(s_kj + δ). g는 주입 선형 진폭, ρ는 같은 방향 비트 템플릿의 해석 신호 상관(위 배경의 계산값과 같은 정의)이다.
  - 다음 조건의 비트 쌍이 하나라도 있으면 M3다. (a) 두 비트의 주입 방향이 다르거나, (b) 같은 방향이지만 극성이 반대이고, I_kj ≥ 0.5다.
  - 0.5는 판별 마진 6 dB에 대응하는 모형 경계다. 이 모형은 반대 방향 상관(약 0.15)과 다중 비트 합산을 무시하므로 실제 경계와 다를 수 있다. G2-int의 경계 칸으로 검증한다.
  - 동기 처프와 비트의 겹침은 M3에 넣지 않는다. 동기 검출 영향은 관측 가능 조건으로 다룬다.
  - **사후 맞춤 위험(기록):** 이 정의는 실험 001 실패 칸(정렬 0 dB)을 포함하도록 만들어졌다. 그러나 개정 2보다 영역이 좁고(정렬 오차 약 10샘플 이내), 경계 양쪽 칸을 미리 고정했다. 결과를 보고 M3를 넓히면 새 실험으로 다룬다.
- **같은 세기 누화를 일괄 제외하지 않는다.** M3 밖이면 같은 세기라도 지연 산출 요구 대상이다.
- **분모 변경 효과(실험 001 수치 재분류, 분석기 변경 없음):**
  - (개정 2 M3 기준, 개정 3까지의 기록) M3를 실험 001 G2에 적용하면 정렬 오차 0인 0 dB 칸(지연 960·4800, 1,920마커, 놓침 1,868)이 빠진다. G2 놓침은 1,889/16,320 = 11.57%에서 21/14,400 = 0.146%가 된다.
  - (개정 4 재계산, 새 M3, 실험 001 순차 신호) 같은 0 dB 정렬 칸 1,920마커 중 새 M3는 1,872마커다. 놓침 1,868건은 전부 새 M3 안이다. 개정 4 기준(조건 1에 +10 dB 여유) G2 지연 산출 요구 대상은 13,152마커, 놓침 21건(0.160%)이었다.
  - (개정 5 재계산, 조건 1 여유 제거) G2 지연 산출 요구 대상은 14,448마커(A0 신호 14,472)이고, 놓침은 21건(0.145%)이다.
  - 어느 쪽이든 놓침 1,889건 중 98.9%를 판정 대상에서 뺀 효과이며, 분석기 개선이 아니다.
  - 결과 보고에는 개정 2 이전 분모 기준 값을 함께 적는다.

## 평가 규약 (개정 5: 주입 플래그 + 누적 의무)

개정 4의 "기본 범주 + 누적 의무" 표를 대체한다.

- **모든 의무(U, K, R, 1a 면제·1b 귀속)는 아래 주입 플래그로만 정의한다.**
- 기본 범주(B7 등)는 **고정 분모 지표의 분모를 정하는 데만** 쓴다. 범주 우선순위가 의무 적용을 가리지 않는다.
- 의무는 누적된다. 같은 사건이 여러 진단 집계에 중복으로 잡힐 수 있다. **적용되는 의무 중 하나라도 위반하면 불합격이다.** 허용 상태가 여럿인 것은 괜찮다.

### 평가 대상 포함 (주입 조건)

- 마커의 기준 시각이 녹음 안이면 평가 대상이다.
  - 실제 경로가 있으면 기준 시각은 최초 실제 경로의 R 시작 시각이다.
  - 실제 경로가 없으면(삭제, 누화 단독) 일정상 L 시작 시각이다. L 신호를 삭제한 경우에도 일정 시각을 쓴다.
- 분석 오류·정렬 실패·L_ok 아님·실행 거부는 평가 대상에서 빼지 않는다.

### 주입 플래그 (분석기 출력과 무관)

W^t = [W_lo^t, W_hi^t]는 정답 W(주입 누화 지연 범위), Z는 주입한 Z다. 구역 경계는 모두 아래 표의 반개·폐구간을 따른다.

**지연 구역** zone(x): 지연 x(자기 마커 L 기준 R−L)에 대해

| 값 | 구간 |
|---|---|
| neg | x < W_lo^t |
| W | W_lo^t ≤ x ≤ W_hi^t |
| Z | W_hi^t < x ≤ W_hi^t + Z |
| guar(보장) | W_hi^t + Z < x ≤ D_max |
| rej(탐지·거부) | D_max < x ≤ D_src |
| unsup(미보장) | x > D_src |

여섯 값은 실수 직선을 빈틈과 겹침 없이 나눈다.

**마커 k의 플래그**

| 플래그 | 정의 |
|---|---|
| real(k) | k의 주입 실제 경로가 하나 이상 있음 |
| xonly(k) | ¬real(k)이고 k의 누화 경로가 있음 |
| zone(k) | real(k)이면 최초 실제 경로 정답 지연 d의 zone(d). ¬real(k)이면 none |
| obs(k) | real(k)이고 최초 경로 관측 가능 조건 1~4 충족. ¬real(k)이면 거짓 |
| Ldmg(k) | L 주입 손상(L 비트 손상, L 삭제, L crop) |
| Ldel(k) | L 신호 삭제(Ldmg의 부분집합) |
| M2(k), M3(k) | 주입 정보로 계산(¬real(k)이면 거짓) |
| safe(k) | 주입 손상 (\|E\|, \|F\|) ∉ {(0, 0), (0, 1), (1, 0)}이거나 비트 전부 무음 |
| edge(k) | zone(k) = guar이고 d − u_inj ≤ W_hi^t + Z 또는 d + u_inj > D_max |

**경로 p의 플래그** (모든 마커의 모든 주입 R 경로)

| 플래그 | 정의 |
|---|---|
| src(p) | p를 낸 마커(출처 마커) |
| ptype(p) | first(최초 실제 경로) / later(후속 실제 경로) / echo / xtalk |
| pzone(p) | p의 지연을 출처 마커 L 기준으로 잰 zone |

**칸의 플래그**

| 플래그 | 정의 |
|---|---|
| cellX | obs_mis / unobs_mis / valid. G8의 주입 누화 이동량으로 사전 지정("고정 평가 집합" G8). G8이 아닌 칸은 valid |
| cellR | 의도된 **실행 단위** 거부 사유 집합: 정렬 실패 주입 칸, 기준점 부족 주입 칸(\|A_inj\| < 3), 1,705개 설정 칸, \|ppm\| > 100 주입 칸. 해당 없으면 ∅. 마커 단위 사유(L 삭제)는 Ldel(k)로 다룬다 |

### 유지 의무 (플래그로만 정의, 관측 가능성·L 손상과 무관)

| 의무 | 적용 조건 | 요구 |
|---|---|---|
| U1 (기준 3) | xonly(k) | Normal(k) 0건 |
| U2 | 모든 k | Normal(k)의 선택 후보가 주입상 ptype = xtalk인 경로이면 위반(출처 마커·칸 종류 무관) |
| U3 | zone(k) ∈ {neg, W, Z} | Normal(k) 0건. Ldmg(k)여도 적용 |
| U4a (기준 8a) | Normal(k)의 선택 후보가 pzone = rej인 경로 p이고 src(p) ≠ k (E2: 실제 오류 t ≤ 6 칸) | 위반 |
| U4b (기준 8b) | zone(k) = rej | Normal(k) 0건. Ldmg(k)여도 적용 |
| U5 (경계, 결정 4) | edge(k) | 분석기 지연 구간 D_c0(k)가 (W_hi + Z, D_max]를 벗어나거나 경계에 걸치면 Normal(k) 0건(A1 8단계). Normal이면 정답 경로·허용치 안(1a) |

### 거부 의무 (칸 단위)

| 의무 | 적용 조건 | 요구 |
|---|---|---|
| R1 | cellX = obs_mis | 실행이 "교정 불일치"로 거부돼야 한다. 비거부는 실패 |
| R2 | cellX = valid | "교정 불일치"를 사유로 한 거부는 실패. 다른 의도된 거부 사유와 구분해 기록하고, 유효 칸 거부율을 따로 보고한다 |
| R3 | cellX = unobs_mis | 거부 여부는 탐지 보장 밖으로 별도 보고(합격 판정 아님). 그 밖의 의무는 그대로 적용 |
| R4 | cellR ≠ ∅ | 해당 사유로 실행을 거부해야 한다. 비거부는 실패 |
| R4m | Ldel(k) | Normal(k) 0건(R 분류 없음, L 분류로 보고) |

- 실행이 거부되면 그 칸의 마커에는 최종 분류가 없다. Normal 금지 의무(U1~U5, R4m)와 K1·K2는 위반이 없다. 고정 분모 지표의 분모에 든 마커는 실패로 센다(분모 정의상 R1·R4 칸의 마커는 분모에 없다).
- 실행 거부는 해당하는 사유를 모두 기록한다. R1·R4는 요구 사유가 기록돼 있으면 만족한다. 고정 평가 집합은 cellX ≠ valid인 칸(G8 불일치 칸)에 cellR 사유를 함께 주입하지 않는다. 따라서 그 조합은 실현 불가 조합이다.

### 일관성 검사 (모든 평가 마커, 위반 0건, 고정 분모 지표가 아님, 결정 5)

| 검사 | 조건 | 위반 |
|---|---|---|
| K1a | 분석기 출력상 R_k에 검출 후보가 하나라도 있음 | 최종 Missing(no_candidate) |
| K1b (개정 3의 8c, 6b 조건부 Missing 금지) | k를 출처로 하는 경로(src(p) = k, 실제·에코·누화) 시작 ±2샘플 안에 검출 후보가 있고 그 후보가 R_k 안에 있음 | 최종 Missing(사유 무관). zone(k) = rej인 마커의 위반은 따로 표시한다 |
| K2 (대응 요구) | 최종 IdUndecodable | c0의 주입상 출처 마커가 k가 아님 |

- K1·K2는 조건이 분석기 출력(검출 여부)에 의존하므로 비율을 내지 않는다. 위반 건수와 사례만 보고한다.
- K1b·K2는 개정 3 대비 **강화**다(개정 4와 같음).

### 잘못 확정 사건의 귀속 (보고 분류)

최종 Normal(k)인데 선택 후보가 k의 first 경로가 아니거나 지연이 허용치를 넘으면 잘못 확정 사건이다. 사건마다 위에서부터 적용한다.

1. ptype(선택) = xtalk → U2 위반. 1a에도 센다.
2. pzone(선택) = unsup → **1c(보고)**. 고정 평가 집합에서 이런 경로는 G7 미보장 칸에만 주입되므로 D1의 칸 단위 적용과 결과가 같다.
3. pzone(선택) = rej → src ≠ k면 U4a 위반. src = k이고 zone(k) = rej면 U4b 위반. src = k이고 zone(k) ≠ rej(자기 최초 경로는 보장 범위 등에 있고 후속 경로·에코만 rej)면 U4 위반이 아니며 1a 위반으로만 센다. 어느 경우든 1a에도 센다. (개정 5.1: 개정 5는 마지막 경우를 U4b로 불렀으나 U4b의 적용 조건 zone(k) = rej와 맞지 않았다. 판정 결과는 같다.)
4. ¬obs(k)이고 src(선택) = k이며 ptype(선택) ∈ {later, echo} 또는 (first이고 허용치 밖) → **1b(보고)**. 관측 불가가 면제하는 것은 이 경우뿐이다.
5. 그 밖 → 1a 위반.

- 1a의 판정 범위는 모든 평가 마커다(zone, Ldmg, cellX와 무관). 귀속 2·4로 간 사건만 1a에서 빠진다.
- U3·U4b·U5 위반은 잘못 확정이 아니어도(정답 경로를 고른 Normal이어도) 그 자체로 위반이다.

### 고정 분모 지표 (분모가 주입 플래그만으로 결정)

- **B7** = real ∧ zone = guar ∧ obs ∧ ¬Ldmg ∧ cellX = valid ∧ cellR = ∅
- **지연 산출 요구 대상** = B7 ∧ ¬M2 ∧ ¬M3 ∧ ¬safe ∧ ¬edge
- **6a-wav 대상** = 지연 산출 요구 대상

| 지표 | 분모(주입) | 성공 | 실패 |
|---|---|---|---|
| 1a 잘못 확정 | 모든 평가 마커 | — | 귀속 1·3·5의 사건 |
| 2 놓침 | 지연 산출 요구 대상 | Normal(정답 경로, 허용치 안) | 그 밖 모든 상태(L 분류, Ambiguous, IdUndecodable, Missing, 판정 불가, 실행 거부 포함) |
| 4 M2·M3 분류 | B7 ∧ (M2 ∨ M3) | Normal(정답), Ambiguous, IdUndecodable(K2 충족), L 분류 | Missing(조건 없이), 잘못 확정, 실행 거부 |
| 6a-dec | 67,584 고정 입력 | 정답 ID 확정 | 확정 거부, 오답 ID |
| 6a-wav | 6a-wav 대상 | 정답 경로 후보에서 정답 ID 확정 | 동기 미검출, 분석 오류, 정렬 실패, L 실패, 확정 거부, 오답 ID, 실행 거부 |
| 6b 안전 실패 분류 | B7 ∧ safe | Normal(정답, "주입 손상 미실현" 진단으로 따로 셈), Ambiguous, IdUndecodable(K2 충족), L 분류 | Missing(조건 없이), 잘못 확정, 실행 거부 |
| edge 보고 | B7 ∧ edge | 판정 아님. 잘못 확정·보류·정답 산출 수와 edge를 빼지 않은 기존 분모 기준 결과를 보고 | (U5·1a 위반은 해당 의무로 판정) |

- B7 ∧ M3 ∧ safe인 마커에는 4와 6b가 함께 적용된다. 허용 집합이 같아 충돌하지 않는다. B7 ∧ edge ∧ (M3 ∨ safe)에도 4·6b가 적용되며, Ambiguous(boundary)가 두 의무와 U5를 함께 만족한다.
- 4와 6b에서 "실행 거부"가 실패인 것은, B7이 cellX = valid ∧ cellR = ∅이라 거부 사유가 없는 칸이기 때문이다.

### 의무 적용표와 지연 산출 요구 대상의 충돌 확인

| 기준 | 적용 조건(주입 플래그) | 지연 산출 요구 대상(요구 대상)과의 관계 | 충돌 |

**동시 만족 결과의 존재(칸 단위 → 마커 단위):**

- cellX = obs_mis 또는 cellR ≠ ∅: 해당 사유로 거부한다. R1·R4를 만족하고, 그 칸에는 분모에 든 마커가 없으며, 나머지 의무는 위반이 없다.
- 그 밖(cellX ∈ {valid, unobs_mis}, cellR = ∅): 실행을 거부하지 않는다. R2·R3을 만족한다. 그다음 마커마다:
  - 요구 대상: 정답 Normal
  - B7 ∧ (M2 ∨ M3 ∨ safe): Ambiguous(4·6b의 허용 집합, K1, Normal 금지를 만족)
  - 그 밖의 마커: Ambiguous. R_k가 비어 있는 출력이면 Missing(no_candidate)도 허용된다(K1a·K1b 위반 아님). 모든 Normal 금지(U1~U5, R4m)와 K1·K2를 만족한다.
