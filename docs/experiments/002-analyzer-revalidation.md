## 배경

실험 001은 기준 1·2·4·5 불합격으로 기각됐다. 이번 실험은 다음 실패 원인을 겨냥한다.

1. 3비트 오정정된 이웃 ID가 earliest 규칙으로 먼저 선택되어, 600ms가 100ms Normal로 확정됐다.
2. 강한 에코가 약한 최초 경로를 가려 에코 지연이 확정됐다.
3. 비트 슬롯 정렬 지연에서 같은 세기 누화와 비트가 겹쳐 ID가 소거됐다.
4. ±100ppm에서 시각 편향이 0.11샘플이었다.

## 분석기 변경 (독립 설계 검증 승인됨, 구현은 미승인)

### 기호

- 후보 c: R 채널 동기 후보 중 관문을 넘고 누화 창 W 밖인 것. 시각은 t_c다.
- 관측 비트 b_c ∈ {0, 1, ⊥}^16. ⊥는 소거다. E_c = {i : b_c,i = ⊥}, e_c = |E_c|.
- cw(m) = `encode_marker_id(m)`
- 비소거 비트 거리: δ_c(m) = |{ i ∉ E_c : b_c,i ≠ cw(m)_i }|
- 지연 범위 마커 집합: M_c = { m ∈ L_ok : W_hi < t_c − t_L(m) ≤ max_delay }. t_L(m)은 선택된 L 후보 시각이다.
- 실제 비트 오류 수 t는 분석기가 모르는 값이다. 시험에서만 주입값으로 안다.

### A3 소거 복호의 오류·소거 예산 (A1보다 먼저 정의)

- 최소 거리 4 부호에서 소거 e개를 뺀 남은 비트의 최소 거리는 4 − e 이상이다.
- 받은 비트가 정답에서 t개 다르고 오답 코드워드 m'까지 거리 τ 이하가 되려면 t ≥ (4 − e) − τ여야 한다. 따라서 정책 (e, τ)에서 오답 확정에 필요한 최소 실제 오류 수는 t_min = 4 − e − τ다.

| 정책 (소거 e, 허용 거리 τ) | 유일 복호 2·τ + e < 4 | 오답 확정 최소 실제 오류 t_min | 채택 |
|---|---|---|---|
| (0, 0) Exact | 예 | 4 | 예 |
| (0, 1) Corrected | 예 | 3 | 예 (현행) |
| (1, 0) ErasureCorrected | 예 | 3 | **예 (신규)** |
| (1, 1) | 예 | 2 | 아니요 |
| (2, 0) | 예 | 2 | 아니요 |
| (3, 0) | 예 | 1 (추가 오류 1개도 검출 불가) | 아니요 |

- 채택 원칙: 확신 ID는 실제 오류가 3개 미만이면 오답이 되지 않아야 한다(t_min ≥ 3). 현행 Corrected와 같은 안전 수준이다.
- **ID 확정 성공:** (e = 0 ∧ min_m δ ≤ 1) 또는 (e = 1 ∧ min_m δ = 0). 해당 m은 부호 성질상 유일하다.
- **ID 확정 거부:** 그 밖의 모든 경우(소거 2개 이상, 소거 1개에 추가 불일치, 소거 0개에 거리 2 이상). 거부된 관측은 A1의 "가능 대응" 계산에만 쓴다.
- 확신 ID의 안전성은 이 부호 예산만으로 보장한다. A1은 같은 관측 비트와 일정을 쓰므로 독립적인 확인 수단이 아니며, A1 통과를 ID 확정의 안전 근거로 삼지 않는다.
- **혼합 오류 시험(필수):**
  - 2048개 ID 전부에 대해 (소거 e, 실제 오류 t) 조합 e ∈ {0, 1, 2, 3}, t ∈ {0, 1, 2, 3, 4}를 주입한다. 위치는 전수 또는 고정 시드 표본이다.
  - ID 확정 성공·거부·오답 확정 수를 센다.
  - 합격 조건: t < t_min인 모든 조합에서 오답 확정 0. t ≥ t_min인 조합의 오답 확정률은 보고만 한다.

### A1 대응 일관성 매칭

- **확신 대응:** confident(c, m) ⟺ m ∈ M_c ∧ A3의 ID 확정 성공 결과가 m이다. 오류 예산은 위 표의 채택 정책이다.
- **가능 대응:** possible(c, m) ⟺ m ∈ M_c ∧ δ_c(m) ≤ T_p, T_p = 3.
  - 뜻: 실제 오류가 3개 이하인 해석은 배제하지 않는다.
  - 소거 비트는 거리 계산에서 빠지므로, 소거가 많을수록 가능 대응이 늘어난다. 소거 16개(비트 전부 무음)면 M_c 전부가 가능 대응이다.
  - confident(c, m) ⟹ possible(c, m)
- S_c = { m : possible(c, m) }
- **마커 k(L_ok)의 판정:**
  1. P_k = { c : k ∈ S_c }. 비어 있으면 실험 001 규칙을 따른다. 창 안 후보가 있으면 Ambiguous(누화), 없으면 Missing.
  2. c0 = P_k 중 t_c가 가장 작은 후보. 동률이면 Ambiguous.
  3. **Normal(k)** ⟺ confident(c0, k) ∧ S_c0 = {k}. 지연은 t_c0 − t_L(k).
  4. **IdUndecodable(k)** ⟺ ¬Normal ∧ S_c0 = {k}. 대응이 일정과 부호로 하나로 정해진 경우다. 지연은 통계에 넣지 않는다.
  5. **Ambiguous(correspondence)** ⟺ |S_c0| ≥ 2.
  6. **IdMismatch(k)** (진단용): P_k가 비어 있고, (t_L(k) + W_hi, t_L(k) + max_delay] 안에 확신 ID m인 후보가 있는데 m ∉ M_c이다(일정과 모순).
- **중복 배정:**
  - 후보 하나는 최대 한 마커의 Normal 또는 IdUndecodable 근거만 된다. S_c0 = {k}일 때만 확정 근거가 되므로 구조상 자동으로 지켜진다.
  - |S_c| ≥ 2인 후보는 여러 마커의 c0이 될 수 있다. 그 마커들은 모두 Ambiguous이고, 그 후보는 확정 근거로 쓰이지 않는다.
- **실제 후보가 없는 마커도 Ambiguous가 될 수 있다.** 다른 마커의 신호인 후보 c가 k ∈ S_c이면(소거가 많거나 δ_c(k) ≤ 3) k는 Missing이 아니라 Ambiguous다. 의도된 동작이며, 삭제 마커가 Ambiguous로 분류되는 비율을 반드시 보고한다.
- **같은 마커의 여러 경로 중 최초 경로 확정 조건:**
  - c0이 P_k의 가장 이른 후보이고 Normal 조건을 만족할 때만 c0을 최초 경로로 확정한다. 뒤의 후보는 R_duplicate로 센다.
  - c0이 확신 대응이 아니면(소거·오류), 뒤에 확신 대응 후보가 있어도 Normal로 확정하지 않는다. c0이 최초 경로일 수 있기 때문이다. 이때 S_c0 = {k}면 IdUndecodable, 아니면 Ambiguous.
  - 관문 아래의 앞선 경로는 P_k에 들어오지 않으므로 이 규칙으로 막을 수 없다. 에코 잘못 확정 위험은 A5가 입증되기 전까지 남는다. 그동안은 분해 한계 지도로 보고한다.
- 실행 전체 지연 중앙값(d̂)은 어떤 판정에도 쓰지 않는다. 실험 001의 2차 해독 불가 배정은 폐기한다.
- **측정 가능률 손실 [가설]:**
  - 1비트 오류 후보는, 지연 범위 안의 다른 마커가 거리 3에 있으면 Ambiguous가 된다.
  - 확장 해밍 [16,11,4]에서 무게 4 코드워드는 140개다. 오류 위치 하나당 거리 3인 코드워드는 140 × 4 / 16 = 35개다.
  - 실제 손실은 일정 ID 집합(0..N−1)과 M_c 크기에 달려 있다. 정확한 조합 계산과 하네스로 확인하기 전까지 수치를 주장하지 않는다.

### A2 임시 방어책 (비교용, 채택 대상 아님)

같은 ID 후보가 지연이 다르게 둘 이상이면 그 마커를 전부 Ambiguous로 한다. A1과 같은 하네스로 돌려, 정상 다중 경로(에코가 최초 경로보다 약한 칸)에서 측정 가능률이 얼마나 떨어지는지 비교 보고한다.

### A4 비트 관문 결합

- 비트 존재 판정은 q와 진폭이 같은 위치·같은 템플릿에서 함께 관문을 넘어야 한다.
- 진단: 실험 001 실패 마커 전부(G2 놓침 1,889건, IdMismatch 122건 포함)에 대해 현행(개별 any)과 결합 관문의 비트 판정·ID 결과·최종 분류 차이를 보고한다.
- 놓침 원인에서 관문 문제를 빼는 판단은 이 비교 뒤에만 한다.

### A5 최초 경로 분리 검사 (분류기 투입 전 별도 시험)

- 방법 후보: 확정 후보 c0 앞 구간 [t_c0 − marker_len, t_c0 − 2·dedup_radius]에서, 검출된 후보들의 재구성 기여를 뺀 잔차의 동기 상관을 다시 구한다. 관문을 넘는 피크가 있으면 "분리 안 된 앞선 경로"다.
- **사용 원칙:** 잔차에서 앞선 경로가 보이지 않았다고 최초 경로가 없다는 증거로 쓰지 않는다. A5는 Normal을 Ambiguous로 낮추는 데만 쓰고, 어떤 확정의 근거로도 쓰지 않는다.
- **투입 조건:**
  - 먼저 작은 합성 시험으로 효과와 오탐을 측정한다. 효과는 에코 잘못 확정 중 Ambiguous로 바뀐 비율, 오탐은 앞선 경로가 없는 정상 칸에서 Ambiguous로 바뀐 비율이다.
  - 효과가 입증되고 오탐이 보고된 뒤에만 분류기에 넣는다. 실험 002 본실행에 넣을지는 그 시험 결과를 보고 사용자가 정한다.

### A6 기준선 전 수정 (실험 001 기록 항목)

- 교정 상태 구분(누화 교정 미실시 / 미검출)
- |o| ≥ 1샘플 거부
- 누화 교정 최소 표본 수
- 마지막 마커 censored 방지(꼬리 무음 또는 max_delay 조정)
- 출력 덮어쓰기 금지
- 요약에 커밋 해시 기록

## 적용 조건

- 신호: `ChirpConfig` 기본값(바꾸지 않음). 신호 재설계는 보류.
- 분석: A1·A3~A5를 적용한 분석기다. `DetectorConfig`는 실험 001 후보 값을 유지한다(q_min 0.4, bit_q_min 0.5, bit_margin_db 6).
- 경로: PCM16 스테레오 WAV → `read_stereo_wav` → `analyze`. 교정값은 주입 정답으로 직접 구성하고, 별도 칸에서 calibrate_* 산출 교정과 비교한다.
- **측정 가능 범위는 세 가지로 구분한다.**
  1. **누화 제외 창 W (교정 계산값):** 실험마다 교정 파일로 계산한다. W = [min(x_min, o) − 2, max(x_max, o) + 2] 샘플(실험 001과 같음).
  2. **분석기 지원 범위 (이 실험으로 확인):** 판정 기준을 만족한 칸의 조건 범위로만 정한다. 누화비, 에코 간격 × 상대 세기, 지연의 비트 슬롯 정렬, SNR, ppm(±100 이내), 채널 오프셋을 다룬다. 값 = `___`(이 실험 결과로 채움). 합격하지 못한 칸은 지원 범위에 넣지 않는다.
  3. **사용 가능 판정 (실제 리그마다):** 리그 자체 검증의 측정값(누화비·누화 지연, 채널 오프셋, R 경로 다중 경로 관측)이 (2) 안에 있는지 판정한다. 값 = `___`(리그 측정 뒤).
- **판정 규칙 (리그 측정 전에 확정):**
  - 리그 측정값은 (2)를 넓히지 않는다. (2)는 검증으로만 바뀐다.
  - 리그 측정값 중 하나라도 (2) 밖이면 그 리그 구성은 **측정 불가**다. 측정 불가 구성으로 얻은 지연은 판정 근거로 쓰지 않는다.
  - (2) 밖의 조건을 쓰려면 그 조건을 포함한 새 검증 실험을 먼저 통과해야 한다.
- 지원 범위 밖의 칸은 판정 기준을 적용하지 않고 분해 한계로 보고한다.
- 칸 구성: 실험 001의 G1~G5와 G5-risk 전부 + 아래 추가 칸.
  - 실험 001에서 실패한 칸 전부(회귀 시험, 같은 시드)
  - 비트 슬롯 정렬 지연과 비정렬 지연의 쌍(960 대 1200 등)
  - 지연 > 마커 간격(600/900ms)과 ID 소거·오정정의 결합
  - 정상 다중 경로: 최초 경로보다 약한 에코 −3/−6/−10 dB, 간격 2~50ms

## 분모

- 주입 마커: 하네스가 생성한 모든 마커. 분석기 출력과 무관하게 하네스가 센다.
- 평가 대상 마커: 주입 마커 − (주입 정답상 censored) − (측정 가능 범위 밖 칸). 분석기 오류·정렬 실패·L_ok 아님은 평가 대상에서 빼지 않는다.
- 잘못 확정 비율 = 잘못 확정 수 / 평가 대상 마커
- 놓침 비율 = 놓침 수 / 구분 가능 마커. 구분 가능 정의는 아래 "정답 경로"
- Ambiguous 비율, 지연 산출 가능 비율(Normal / L_ok)은 전체와 그룹별로 보고한다.
- ID 손상 시험은 "정확한 ID 복원"과 "안전한 실패 분류"로 분모를 나눈다(아래).

## 정답 경로

- **최초 경로:** 마커마다 주입한 경로 중 가장 이른 실제 경로다. 누화(창 W 안)는 실제 경로가 아니다.
- **정답 지연:** 최초 경로의 주입 R−L 시간차(원시, 주입 오프셋과 ppm 포함)다.
- **에코 확정 = 잘못 확정.** Normal 지연이 최초 경로가 아닌 다른 경로(에코, 다른 마커)의 지연이면 잘못 확정이다.
- **구분 가능(주입 조건만으로 판정, 실험 001 개정 3의 5개 조건을 승계):**
  1. 정답 실제 경로가 있다.
  2. 주입 지연이 W 밖이고 max_delay 이하다.
  3. SNR ≥ 10 dB이거나 잡음이 없다.
  4. 다른 모든 경로가 ±marker_len 밖이거나, 레벨이 최초 경로 이하다.
  5. 다른 모든 경로와의 간격이 2×dedup_radius 이상이다.
  - 추가: 측정 가능 범위 안이다.

## 모호함 허용 조건

- 다음은 Normal이 아니어도 실패가 아니다. 최종 분류가 Normal(정답)·Ambiguous·IdUndecodable(대응 확인) 중 하나면 된다.
  - (M1) 최초 경로보다 강한 경로가 ±marker_len 안에 있다. 에코 분리 불가 조건이다.
  - (M2) 후보 S_c0에 다른 마커가 포함될 수 있는 주입 조건이다. 3비트 이상 오류, 소거 4개 이상과 지연 > 간격의 결합이 여기에 해당한다.
  - (M3) 강한 누화(누화 레벨 ≥ 실제 레벨)가 ±marker_len 안에 있다.
- **IdUndecodable은 대응이 확인된 경우만 허용한다.** 주입 정답의 마커와 분석기가 배정한 마커가 같아야 한다. 대응이 틀린 IdUndecodable은 실패다. 대응 불명이면 Ambiguous여야 한다.
- Missing("마커 미검출, 원인 미확정")은 다음 조건에서만 허용한다. 실제 경로 레벨이 관문 아래이거나, 주입 정답상 실제 경로가 없다(삭제 마커). 그 밖의 Missing은 놓침 또는 실패다.

## 판정 기준 (초안, 사용자 승인 뒤 확정·이후 변경 금지)

| # | 기준 | 합격선 |
|---|---|---|
| 1 | 잘못 확정 (에코·다른 마커 지연 확정 포함, 평가 대상 전부) | 0건 |
| 2 | 놓침 (구분 가능 마커) | 전체 ≤ 0.5%, 칸별 ≤ 5% |
| 3 | 누화 단독(R 연결 해제 모사) | Normal 0건 |
| 4 | 모호함 허용 조건 M1~M3의 분류 | 허용 분류 외 0건. 대응이 틀린 IdUndecodable 0건 |
| 5a | 단일 경로 알고리즘 정확도(합성, 잡음 없음, ppm 없음) | 최대 절대 오차 ≤ 0.05샘플 |
| 5b | ±100ppm을 포함한 합성 단일 경로 정확도 | 최대 절대 오차 ≤ 0.5샘플(**후보 기준**, 사용자 승인). 합성 시험 조건의 오차 한도이며 실제 리그 전체 정확도를 보장하지 않는다 |
| 6a | 정확한 ID 복원: 1비트 오류, 소거 ≤3 | Exact/Corrected/ErasureCorrected로 정답 ID 100% |
| 6b | 안전한 실패 분류: 2비트 오류, 소거 ≥4, 비트 무음, 3비트 오정정 | 다른 마커로 Normal 확정 0, Missing 0. 대응 확인된 IdUndecodable 또는 Ambiguous만 허용 |
| 7 | 실험 001 회귀 | 실험 001의 잘못 확정 428건이 전부 잘못 확정이 아니어야 함. 나머지 실패 마커는 기준 1~6으로 판정. 오확정 해소와 함께, 실험 001 대비 Normal·지연 산출 가능 비율 변화(측정 가능률 저하)를 칸별로 보고 |
| 8 | 플랫폼 | 1~7을 Windows(로컬 또는 CI)와 Linux(CI) 양쪽에서 충족. 해당 커밋의 CI 통과가 필요함 |

- **5b 허용치 근거(후보 기준으로 승인됨):**
  - 지연 판정의 최소 단위는 1ms다(`AGENTS.md`: 1ms 미만 차이는 판정 보류).
  - 0.5샘플은 10.4µs로 그 1%다.
  - ±100ppm은 실행 안에서 거의 일정한 편향이라, 실행 간 비교에서 대부분 상쇄된다 [추정].
  - 채널 오프셋 자체 검증은 같은 ADC 시계의 두 채널을 쓰므로 ppm과 무관하다. 5a 정확도로 충분하다.
- **A2 비교 보고(판정 아님):** 정상 다중 경로 칸에서 A1 대비 A2의 지연 산출 가능 비율 차이.
- **CI 통과와 실험 합격은 다르다.** 하네스는 기준을 단정하지 않고 수치만 낸다. 그래서 기준을 못 맞춰도 정상 종료하며, CI가 초록이어도 실험은 불합격일 수 있다. 실험 판정은 위 표의 수치로만 한다. 보고할 때는 "CI 통과/실패"와 "기준 합격/불합격"을 따로 적는다.
- **채택:** 1~8을 모두 충족하면 신호와 분석 기준을 동결한다. 측정 가능 범위의 빈칸은 리그 자체 검증 뒤 채우고, 그 전까지 동결은 "합성 조건 한정"으로 표기한다.
- **실패:** 기준을 바꾸지 않는다. 원인을 실험 001과 같은 (i)~(iv)로 분류한다. (i) 동기·비트 구분 능력이 원인이면 신호 재설계(A안)를 검토한다.
