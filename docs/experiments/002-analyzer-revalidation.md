## 분석기·신호 변경 (설계 검증 대상, 구현 미승인)

### 기호

- 일정 마커 집합 𝒦: 생성기 일정의 모든 마커. L 검출 여부와 관계없다.
- 예측 L 시각 t̂_L(m): L 정렬(기준점 최소제곱)로 예측한 마커 m의 시각. 모든 m ∈ 𝒦에 대해 정의된다.
- 실측 L 시각 t_L(m): 선택된 L 후보의 시각. L_ok인 마커에만 있다.
- 후보 c: R 채널 동기 후보 중 관문을 넘은 것. 시각은 t_c다.
- 관측 비트 b_c ∈ {0, 1, ⊥}^16. ⊥는 소거다. E_c = 소거 위치 집합, e_c = |E_c|.
- cw(m): 마커 m에 배치된 코드워드(A0의 배치표).
- 비소거 비트 거리: δ_c(m) = |{ i ∉ E_c : b_c,i ≠ cw(m)_i }|
- 실제 비트 오류 수 t는 소거되지 않은 위치에서 실제로 뒤집힌 비트 수다. 분석기는 모르고, 시험에서만 주입값으로 안다.

### 지연 범위 (보장·탐지·미보장)

| 구간 (R − L 지연 d) | 이름 | 분석기 보장 |
|---|---|---|
| d ∈ W (누화 제외 창) | 누화 창 | Normal 금지(실험 001과 같음) |
| W_hi < d ≤ D_max | **보장 범위** | 판정 기준 1~7을 적용한다. D_max = max_delay = 48000샘플(1000ms) |
| D_max < d ≤ D_src | **탐지·거부 범위** | 이 신호는 어떤 마커의 Normal도 되지 않는다(A0 거리 조건과 오류 예산 안에서). 자기 마커는 Ambiguous(out_of_support)가 되고, 실행 경고 `delay_beyond_support`를 낸다. D_src = 96000샘플(2000ms) |
| d > D_src | **미보장 범위** | 탐지를 보장하지 않는다. 일정 밖이나 창 밖 확신 ID는 IdMismatch·orphan 진단으로 드러날 수 있다. 그러나 창 안 마커로 오정정되는 것은 일반 부호 거리(4)만큼만 보호된다 |

- 출처 탐색 창: 후보 c의 출처 후보는 M_c = { m ∈ 𝒦 : W_hi < t_c − t̂_L(m) ≤ D_src }다. **L_ok로 제한하지 않는다.** L 해독 실패는 대안 출처를 지우는 근거가 아니다.
- 측정 대상: Normal·IdUndecodable은 L_ok 마커에만 준다. 지연은 실측 t_L(m) 기준이다.
- 실제 리그에서 D_max 밖 지연이 관측되면, 그 실행은 지원 범위 밖 마커를 포함한다고 보고한다(아래 "사용 가능 판정").

### A0 ID 배치 변경 (신호 변경)

- **변경 내용:**
  - 마커 순번 i → 코드워드 인덱스 π(i)의 결정적 배치표를 둔다. 현행은 π(i) = i다.
  - 조건: 출처 탐색 창에 동시에 들어올 수 있는 모든 마커 쌍(창 전체)의 코드 거리가 8 이상이다.
- **창 안 동시 마커 수:**
  - 기본 설정(간격 24000, D_src 96000)에서 출처 탐색 창에 들어오는 마커는 ⌊D_src / interval⌋ + 1 = 5개다.
  - ppm·경계 여유를 두어 **연속 6개 마커의 모든 쌍**에 거리 ≥ 8을 요구한다.
- **실현 가능성 [사실, 리뷰어 계산]:**
  - 탐욕 배치로 연속 6개 모든 쌍 거리 ≥ 8을 만족하는 길이 1,704의 순서를 얻었다. 전수 검사 위반 0이다.
  - 연속 5개 기준은 1,801, 7개는 1,486, 9개는 1,254다.
  - 배치 알고리즘과 표는 구현 단계에서 결정적으로 고정하고 테스트로 보호한다.
- **지원 최대 마커 수:** 배치표 길이(연속 6개 기준 1,704)로 한다. `MAX_MARKERS`를 이 값 이하로 바꾼다.
  - ID는 재사용하지 않는다. 마커 수가 표 길이를 넘는 설정은 거부한다.
  - 일정 끝에는 배치표의 앞부분을 다시 쓰지 않는다(순환 없음).
- **거리 조건 안에서만 성립하는 주장:**
  - 출처 창 안 다른 마커와의 거리가 8 이상이면, 창 안 다른 마커로 잘못 확신 확정되려면 실제 오류 t ≥ 8 − e − τ가 필요하다. Corrected는 7, ErasureCorrected는 7, Exact는 8이다.
  - 같은 조건에서 창 안 다른 마커가 가능 대응(δ ≤ 3)이 되려면 t ≥ 5 − e가 필요하다. 따라서 소거 0개·실제 오류 1개 후보는 창 안의 다른 마커와 모호해지지 않는다("1비트 손실 0%"는 이 조건 안의 주장이다).
  - 소거가 늘면 이 보호는 줄어든다(e = 4이면 t = 1에서도 가능 대응이 생길 수 있다).
  - 창 밖 출처(미보장 범위)와 일정 밖 신호에는 이 보장이 없다.
- **검증 항목(설계 검증·구현 테스트 둘 다):**
  1. 배치표 전수 검사: 창 전체(연속 6개)의 모든 쌍이 거리 ≥ 8. 일정 끝, 지원 최대 마커 수, 마커 수 1 ~ 최대 전 구간에서 확인한다.
  2. 실제 일정 시각(ppm ±100, 경계 여유 포함)에서 M_c에 함께 들어오는 마커 집합이 연속 6개 안에 들어가는지 전수 확인한다.
  3. 소거·혼합 오류·L 해독 실패가 있을 때 오확정이 없는지, 하네스의 혼합 오류 칸으로 확인한다(아래 G6).

### A3 소거 복호의 오류·소거 예산

- 소거 e개를 뺀 펑처드 부호의 최소 거리는 정확히 4 − e다(개정 1 설계 검증에서 증명, 패리티 비트 포함 모든 소거 위치).
- 정책 (e, τ)에서 오답 확정에 필요한 최소 실제 오류 수는 t_min = 4 − e − τ다. 이것은 전체 부호 기준이고, A0 배치는 창 안에서 이 값을 키운다.

| 정책 (소거 e, 허용 거리 τ) | 유일 복호 2τ + e < 4 | t_min (전체 부호) | 채택 |
|---|---|---|---|
| (0, 0) Exact | 예 | 4 | 예 |
| (0, 1) Corrected | 예 | 3 | 예 (현행) |
| (1, 0) ErasureCorrected | 예 | 3 | **예 (신규)** |
| (1, 1) | 예 | 2 | 아니요 |
| (2, 0) | 예 | 2 | 아니요 |
| (3, 0) | 예 | 1 | 아니요 |

- **ID 확정 성공:** (e = 0 ∧ min δ ≤ 1) 또는 (e = 1 ∧ min δ = 0). 최소 거리 탐색은 일정이 아니라 **2048개 전체 코드워드**에서 한다. 찾은 코드워드가 배치표에 없으면 확정 실패(일정 밖 ID)로 진단한다.
- **ID 확정 거부:** 그 밖의 모든 경우. **e ≥ 2이면 항상 거부한다.** 거부된 관측은 A1의 가능 대응 계산에만 쓴다.
- 확신 ID의 안전성은 이 부호 예산과 A0 거리로만 보장한다. A1은 같은 관측 비트와 일정을 쓰므로 독립적인 확인 수단이 아니다.
- **혼합 오류 시험(필수, 구현 테스트):**
  - 2048개 코드워드 전부에 대해 (e, t) ∈ {0..3} × {0..4}를 주입한다. 소거 위치와 오류 위치는 겹치지 않는다.
  - t < t_min 조합은 위치 전수로 시험한다. 합격 조건은 오답 확정 0이다.
  - t ≥ t_min 조합은 고정 시드 표본으로 오답 확정률을 보고한다.
  - 같은 시험을 A0 배치의 창 안 마커 집합으로 다시 해 창 기준 t_min(7, 8)을 확인한다.

### A1 출처 일관성 매칭

- **확신 대응:** confident(c, m) ⟺ m ∈ M_c ∧ A3 ID 확정 성공 결과가 cw(m)이다.
- **가능 대응:** possible(c, m) ⟺ m ∈ M_c ∧ δ_c(m) ≤ T_p, T_p = 3(설계 후보). 소거 16개면 M_c 전부가 가능 대응이다. confident ⟹ possible.
- S_c = { m : possible(c, m) }
- **마커 k의 판정 순서(앞 단계가 결정하면 종료):**
  1. **L 불확실:** k가 L_ok가 아니거나 L 후보 선택이 유일하지 않으면(같은 ID의 L 후보가 둘 이상이고 시각 차이가 2샘플을 넘음) Normal·IdUndecodable을 주지 않는다. L_ok가 아니면 R 분류 대상에서 빠지고 L 분류로 보고한다. L 선택이 유일하지 않으면 Ambiguous(l_ambiguous)다.
  2. P_k = { c : k ∈ S_c, t_c − t_L(k) ∈ (W_hi, D_src] }
  3. P_k가 비면 다음으로 나눈다.
     - 창 안 후보가 있으면 Ambiguous(xtalk_like 또는 abnormal_near)
     - (t_L(k) + W_hi, t_L(k) + D_max] 안에 어떤 마커에도 가능 대응이 없는 동기 후보가 있으면 Missing(unassigned_candidate). 진단으로 보존하고 단순 미검출과 구분한다.
     - 그 밖에는 Missing(no_candidate)
  4. c0 = P_k 중 t_c가 가장 작은 후보. 서로 다른 후보가 2샘플 안에서 동률이면 Ambiguous(tie). 같은 후보의 중복 기록은 동률이 아니다.
  5. t_c0 − t_L(k) > D_max이면 Ambiguous(out_of_support)
  6. **Normal(k)** ⟺ confident(c0, k) ∧ S_c0 = {k}. 지연은 t_c0 − t_L(k)다.
  7. **IdUndecodable(k)** ⟺ ¬Normal ∧ S_c0 = {k}
  8. 그 밖(|S_c0| ≥ 2)은 **Ambiguous(correspondence)**
  9. **IdMismatch(k)** (진단): 3단계에서 P_k가 비었는데, k의 보장 범위 안에 일정 밖 ID나 창 밖 출처로 확신 확정된 후보가 있는 경우. 3단계의 Missing보다 먼저 적용한다.
- **중복 배정:**
  - 후보 하나는 최대 한 마커의 Normal·IdUndecodable 근거만 된다(S_c0 = {k}일 때만 근거가 되므로 구조상 성립).
  - |S_c| ≥ 2인 후보는 여러 마커의 Ambiguous 근거가 될 수 있다.
  - R_duplicate는 Normal로 확정된 마커의 c0 뒤 후보 중 S_c = {k}인 것만 센다. |S_c| ≥ 2인 후보는 R_shared로 따로 센다.
- **실제 후보가 없는 마커:** 다른 마커의 신호인 후보 c가 k ∈ S_c를 만족하면 k는 Ambiguous가 된다. 삭제 마커의 분류 분포를 반드시 보고한다.
- **최초 경로 확정 조건:**
  - c0이 P_k에서 가장 이르고 Normal 조건을 만족할 때만 확정한다.
  - c0이 확신 대응이 아니면 뒤에 확신 후보가 있어도 Normal을 주지 않는다.
- **차단 원인별 보고:**
  - 자기 최초 경로의 ID 불확실성 때문에 차단된 수
  - 다른 마커·누화 후보 때문에 차단된 수
  - 뒤에 정답 확신 후보가 있었지만 차단된 수
  - 삭제 마커로 번진 Ambiguous 수
- **보장하지 않는 것(명시):**
  - 관문 아래의 앞선 경로. P_k에 들어오지 않으므로 뒤 경로가 Normal이 될 수 있다(실험 001 G3 유형).
  - A0 거리 조건 밖의 오류 수(창 안 t ≥ 7)
  - 미보장 지연 범위
  - 이 위험은 분해 한계 지도와 기준 1의 칸별 결과로 드러난다.
- 실행 전체 지연 중앙값(d̂)은 어떤 판정에도 쓰지 않는다.
- **T_p = 3의 비용 [사실, 리뷰어·설계 검증 계산, A0 없음]:**
  - 순차 ID(현행 π(i) = i)에서는 인접 마커 쌍의 대부분이 거리 4다(600개 일정에서 525/599쌍).
  - 그래서 소거 0개·1비트 오류 후보의 21.875%(ID 0..599), 21.25%(ID 0..19)가 Ambiguous가 된다.
  - A0을 적용하면 위 조건에서 0%다(A0 절의 조건 한정 주장).

### A2 임시 방어책 (비교용, 채택 대상 아님)

같은 ID 후보가 지연이 다르게 둘 이상이면 그 마커를 전부 Ambiguous로 한다. A1과 같은 하네스로 돌려, 정상 다중 경로(에코가 최초 경로보다 약한 칸)에서 측정 가능률이 얼마나 떨어지는지 비교 보고한다.

### A4 비트 존재 관문 결합

- 의미 확정: 비트 존재 판정만, q와 진폭이 같은 위치·같은 템플릿에서 함께 관문을 넘도록 바꾼다. 비트 방향(peaks)과 6 dB 마진 계산은 바꾸지 않는다.
- [사실, 설계 검증] 이 변경 뒤 존재하는 비트는 현행에서도 존재한다(단조). 기존 소거를 복원하지 않고, 소거를 늘릴 수만 있다.
- 진단 목적은 두 가지로 나눈다.
  - 거짓 비소거 제거: 현행에서 존재로 판정됐지만 같은 위치에서는 관문을 넘지 못한 비트의 수와 그 영향(IdMismatch 122건 포함)
  - 최종 분류 변화
- "관문을 통과한 템플릿이 비트 승자 템플릿이어야 한다"는 조건은 이번에 넣지 않는다. 별도 변경으로 기록만 한다.

### A5 최초 경로 분리 검사 (보조 검사, 분류기 투입 전 별도 시험)

- 방법 후보: c0 앞 구간에서 검출된 후보들의 재구성 기여를 뺀 잔차의 동기 상관을 다시 구한다. 관문을 넘는 피크가 있으면 Normal을 Ambiguous(unresolved_earlier_path)로 낮춘다.
- **사용 원칙:**
  - 잔차에서 앞선 경로가 보이지 않았다고 최초 경로가 없다는 증거로 쓰지 않는다.
  - A5는 Normal을 낮추는 데만 쓴다.
  - 1ms(48샘플) 간격처럼 검사 구간 밖인 조건은 덮지 못한다. 기준 7(428건 해소)을 A5에 의존하지 않는다.
- **작은 시험(사전 고정):**
  - 칸: 단일 경로 대조군, 그리고 앞선 약한 경로가 있는 쌍
  - 간격: 48 / 96 / 240 / 960 / 2400샘플과 검사 구간 양쪽 경계
  - 앞선 경로 상대 레벨: −3 / −6 / −10 dB
  - 극성 양쪽, 분수 위치 0 / 0.5, ppm 0 / ±100
  - 정답 파라미터로 제거한 결과와 추정 파라미터로 제거한 결과를 나눈다.
  - 원신호 기준 진폭 관문을 유지한다.
- **합격선(제안값, 사용자 승인 필요):**
  - 효과율: 검사 구간 안 조건의 에코 잘못 확정 중 Ambiguous로 바뀐 비율 ≥ 90%
  - 정상 오탐률: 대조군에서 Ambiguous로 바뀐 비율 ≤ 1%
  - 합격하면 분류기 투입을 사용자에게 제안한다. 실패하면 A5는 넣지 않는다.

## 적용 조건

- 신호: `ChirpConfig` 기본값 + A0 ID 배치. 파형 구조는 바꾸지 않는다.
- 분석:
  - A1·A3·A4·A6를 적용한 분석기
  - A5는 작은 시험 합격과 사용자 승인 뒤에만 넣는다.
  - `DetectorConfig`는 실험 001 후보 값을 유지한다(q_min 0.4, bit_q_min 0.5, bit_margin_db 6).
  - 지연 범위: D_max 1000ms, D_src 2000ms
- 경로: PCM16 스테레오 WAV → `read_stereo_wav` → `analyze`. 교정값은 주입 정답으로 직접 구성하고, 별도 칸에서 calibrate_* 산출 교정과 비교한다.

### 측정 가능 범위 (세 가지 구분)

1. **누화 제외 창 W (교정 계산값):** 실험마다 교정 파일로 계산한다. W = [min(x_min, o) − w, max(x_max, o) + w], w = max(2, 4·σ_cal)샘플.
2. **분석기 지원 범위 (이 실험으로 확인):**
   - 고정 평가 집합의 결과에서, 판정 기준을 만족한 조건의 범위로 보고한다. 누화·에코의 지연 차이 × 상대 레벨 × 비트 슬롯 정렬, SNR, ppm(±100 이내), 채널 오프셋, 지연(보장 범위)을 다룬다. 값 = `___`(실험 결과)
   - 지원 범위는 판정 대상을 줄이는 데 쓰지 않는다(아래 "고정 평가 집합").
   - 검증하지 않은 조건 조합을 각 축의 최솟값·최댓값으로 묶어 범위를 넓히지 않는다.
3. **사용 가능 판정 (실제 리그마다):**
   - 리그 자체 교정 결과(누화비·누화 지연·산포, 채널 오프셋, ppm 추정)가 (2) 안인지 판정한다. 값 = `___`(리그 측정 뒤)
   - 리그 측정값은 (2)를 넓히지 않는다. (2)는 검증으로만 바뀐다.
   - 교정 결과가 (2) 밖이면 그 리그 구성은 **측정 불가**다.
   - 교정 결과가 (2) 안이면 실행을 진행한다. 누화와 실제 경로의 세기가 비슷하다는 이유만으로 실행 전체를 빼지 않는다. 마커마다 경로를 구분할 수 없으면 그 마커는 Ambiguous로 보고한다.
   - 실행 중 지원 범위 밖 마커(D_max 초과 지연, 구조적 비트 중첩 등)는 마커별로 Ambiguous나 경고로 보고한다. 그 비율을 실행 요약에 낸다.
   - **한계(명시):** 실제 리그에서 실제 경로의 세기는 R에서 검출된 후보의 진폭으로만 알 수 있다. 관문 아래에 숨은 앞선 경로가 없다는 것을 관측만으로 독립 확인할 수는 없다. 그래서 "지원 범위 안"이라는 판정은 검출된 경로 기준이며, 숨은 경로에 대해서는 보장하지 않는다.

## 고정 평가 집합

- 아래 칸 전부가 평가 집합이다. 실험 시작 전에 칸 목록과 시드를 고정하고, 결과를 보고 칸을 빼거나 더하지 않는다.
  - **G1~G5, G5-risk:** 실험 001의 칸 정의와 시드를 그대로 쓴다(회귀).
  - **G2-slot:** 누화와 실제 경로의 지연 차이를 비트 슬롯 기준으로 나눈 쌍.
    - 지연 차이 Δ ∈ {960, 1200, 1440, 4800, 5040}샘플. 슬롯 정렬, 반 슬롯, 정렬을 반복해 비교한다.
    - 지연 차이 Δ ∈ {960 ± 24, 960 ± 48}샘플: 정렬 경계 근처
    - 상대 레벨: 실제 − 누화 ∈ {−6, −3, 0, +3, +6, +10, +20} dB
    - 극성: 4조합
  - **G3-normal:** 정상 다중 경로. 에코가 최초 경로보다 약한 칸으로, 상대 −3 / −6 / −10 dB, 간격 2 / 5 / 10 / 20 / 50ms
  - **G6 혼합 손상:**
    - 주입 오류 마스크 F(뒤집기)와 소거 마스크 E(비트 무음)의 조합 (|E|, |F|) ∈ {0..4} × {0..4}
    - 위 조합을 L 해독 실패(L 쪽 비트 손상)와 결합한다.
    - 지연 960 / 28800 / 43200샘플(20 / 600 / 900ms)
  - **G7 범위 밖 지연:**
    - 지연 52800 / 72000 / 91200샘플(1100 / 1500 / 1900ms, 탐지·거부 범위)
    - 지연 100800 / 120000 / 240000샘플(2100 / 2500 / 5000ms, 미보장 범위)
    - 각각 비트 오류 0~6개를 결합한다.
    - 범위 밖 신호가 범위 안의 다른 마커로 오확정되는 반례를 겨냥한다.
  - **G8 누화 창 경계:** 교정 산포 σ_cal을 주입하고, 실제 누화 지연이 창 경계 ±1샘플인 칸
  - **G9 일정 끝·최대 마커 수:** 마커 수 = 지원 최대값, 그리고 일정 끝 직전·직후의 마커
- 칸마다 마커 20개 이상, 실제 경로 마커는 합계 20,000개 이상이다.

## 분모

- **주입 마커:** 하네스가 생성한 모든 마커. 분석기 출력과 무관하게 하네스가 센다.
- **평가 대상 마커:** 주입 마커 − (주입 정답상 censored). 분석기 오류·정렬 실패·L_ok 아님은 평가 대상에서 빼지 않는다.
- **지연 산출 요구 대상:** 평가 대상 중 아래 "모호함 허용 조건"과 "안전한 실패 분류 대상"에 들지 않고, "구분 가능"인 마커
- **안전한 실패 분류 대상:** 주입 손상이 A3 확정 예산 밖인 마커. (|E|, |F|) ∉ {(0, 0), (0, 1), (1, 0)}인 경우와 비트 전부 무음인 경우다.
- 보고 비율:
  - 잘못 확정 비율 = 잘못 확정 / 평가 대상
  - 놓침 비율 = 놓침 / 지연 산출 요구 대상
  - Normal / 평가 대상, L_ok / 평가 대상, Normal / L_ok
  - Ambiguous / 평가 대상(사유별)
  - 위 비율들은 전체, 그룹별, 칸별로 낸다. 모호함 허용 칸과 안전한 실패 분류 칸도 전체 평가 집합 기준의 비율에 계속 포함해 보고한다.

## 정답 경로

- **최초 경로:** 마커마다 주입한 실제 경로 중 가장 이른 것. 누화(주입 지연이 교정 창 W 안)는 실제 경로가 아니다.
- **정답 지연:** 최초 경로의 주입 R−L 시간차다(원시, 주입 오프셋과 ppm 포함).
- **에코·다른 마커 확정 = 잘못 확정.** Normal 지연이 최초 경로가 아닌 경로(에코, 다른 마커, 누화)의 지연이면 잘못 확정이다.
- **시각 허용치(주입 기준):**
  - 주입 메타데이터상 다른 경로가 ±marker_len 안에 있으면 2샘플, 아니면 0.5샘플이다.
  - ppm 칸은 기준 5b를 따른다.
  - 분석기 overlap 표시는 허용치 결정에 쓰지 않는다.
- **구분 가능(주입 조건만으로 판정):**
  1. 정답 실제 경로가 있다.
  2. 주입 지연이 W 밖이고 D_max 이하다.
  3. SNR ≥ 10 dB이거나 잡음이 없다.
  4. 다른 모든 경로가 ±marker_len 밖이거나, 주입 레벨이 최초 경로 이하다.
  5. 다른 모든 경로와의 간격이 2×dedup_radius(96샘플) 이상이다.

## 모호함 허용 조건 (주입 조건으로 사전 정의)

아래 조건의 마커는 지연 산출 요구 대상에서 빠진다(놓침 판정 안 함). 그러나 **평가 집합에는 남고, 잘못 확정은 0이어야 한다.** 허용 분류는 Normal(정답)·Ambiguous·IdUndecodable(대응 확인)이다.

- **(M1) 앞선 경로보다 강한 뒤 경로:** 최초 경로보다 주입 레벨이 높은 다른 경로가 ±marker_len 안에 있다.
- **(M2) 주입 비트 손상의 대응 모호:** G5·G6의 주입 오류 마스크 F와 소거 마스크 E로 예상 관측 b^inj를 만든다. 다음을 만족하면 M2다.

  ∃ m ≠ k : m ∈ M^truth(k) ∧ δ^inj(m) ≤ 3

  - M^truth(k)는 주입 시각과 **전체 일정**으로 계산한 출처 탐색 창의 마커 집합이다(L_ok를 쓰지 않는다).
  - 누화·에코 혼합으로 생긴 소거에는 M2를 적용하지 않는다. 그 경우는 M3로만 다룬다.
- **(M3) 구조적 비트 중첩:** 다음을 모두 만족하는 다른 경로(누화 또는 에코)가 있다.
  - 지연 차이 Δ(다른 경로와 실제 경로의 주입 시작 차이)가 ±marker_len 안이다.
  - 비트 슬롯 정렬: (Δ mod 480)이 48샘플 이하이거나 432 이상이다. 비트 처프의 87.5% 이상이 상대 경로의 비트 처프와 겹친다.
  - 주입 상대 레벨: 다른 경로 레벨 ≥ 실제 경로 레벨 − 6 dB. 근거: 비트 판별 마진이 6 dB이므로, 방향이 반대인 정렬 비트가 이 범위에 있으면 마진을 만족할 수 없다(극성 무관).
  - 극성 조합은 모두 포함한다(같은 방향·반대 극성은 상쇄, 반대 방향은 마진 붕괴).
- **같은 세기 누화를 일괄 제외하지 않는다.** M3 밖이면(예: 반 슬롯 어긋남, 실제 경로가 6 dB 넘게 강함) 같은 세기라도 지연 산출 요구 대상이다.
- **분모 변경 효과(실험 001 수치를 재분류, 분석기 변경 없음):**
  - M3를 실험 001 G2에 적용하면 지연 960·4800의 0 dB 칸(1,920마커, 놓침 1,868)이 빠진다. +10 dB 칸은 남는다.
  - 그 결과 G2 놓침은 1,889/16,320 = 11.57%에서 21/14,400 = 0.146%로 바뀐다.
  - 이것은 분모 변경 효과이며, 분석기가 개선된 것이 아니다. 실험 002 결과 보고에도 이 사실을 함께 적는다.
- **IdUndecodable은 대응이 맞을 때만 허용한다.** 주입 정답의 출처 마커와 분석기가 배정한 마커가 같아야 한다. 대응이 틀린 IdUndecodable은 실패이고, 대응 불명이면 Ambiguous여야 한다.
- **Missing("마커 미검출, 원인 미확정")은 다음만 허용한다.**
  - 실제 경로의 주입 레벨이 관문 아래
  - 주입 정답상 실제 경로가 없음(삭제 마커)
  - 그 밖의 Missing은 실패다(지연 산출 요구 대상이면 놓침, 아니면 기준 4 위반).

## 판정 기준 (초안, 사용자 승인 뒤 확정·이후 변경 금지)

| # | 기준 | 합격선 |
|---|---|---|
| 1 | 잘못 확정 (에코·다른 마커·누화 지연 확정 포함, 평가 대상 전부, 모호함 허용·안전 실패 칸 포함) | 0건 |
| 2 | 놓침 (지연 산출 요구 대상) | 전체 ≤ 0.5%, 칸별 ≤ 5% |
| 3 | 누화 단독(R 연결 해제 모사), G8 누화 창 경계 | Normal 0건 |
| 4 | 모호함 허용 조건 M1~M3 마커의 분류 | 허용 분류 외 0건. 대응이 틀린 IdUndecodable 0건 |
| 5a | 단일 경로 알고리즘 정확도(합성, 잡음 없음, ppm 없음) | 최대 절대 오차 ≤ 0.05샘플 |
| 5b | ±100ppm을 포함한 합성 단일 경로 정확도 | 최대 절대 오차 ≤ 0.5샘플(후보 기준). 합성 시험 조건의 오차 한도이며 실제 리그 전체 정확도 보장이 아님 |
| 6a | 정확한 ID 복원: 주입 (|E|, |F|) ∈ {(0, 0), (0, 1), (1, 0)} | ID 확정 결과가 정답 ID 100%. 최종 Normal 여부는 6a가 아니라 기준 1·2로 따로 판정 |
| 6b | 안전한 실패 분류: 6a 밖의 주입 손상(G5, G6) | 잘못 확정 0, Missing 0. 대응이 맞는 IdUndecodable 또는 Ambiguous만 허용 |
| 6c | A3 혼합 오류 시험(구현 테스트) | t < t_min 전 조합 오답 확정 0(전체 부호와 A0 창 기준 둘 다) |
| 7 | 실험 001 회귀 | 실험 001 잘못 확정 428건 전부 해소. 나머지 실패 마커는 기준 1~6으로 판정. 측정 가능률 변화(실험 001 대비 Normal/평가 대상, Normal/L_ok)를 칸별로 보고 |
| 8 | 범위 밖 지연(G7) | 탐지·거부 범위(D_max < d ≤ D_src, 오류 ≤ 6): 어떤 마커의 Normal도 0건이고, 자기 마커는 Ambiguous(out_of_support). 미보장 범위: 결과 분포만 보고(판정 아님) |
| 9 | 플랫폼 | 1~8을 Windows와 Linux(CI) 양쪽에서 충족. 해당 커밋의 CI 통과 필요 |

- **5b 허용치 근거:**
  - 지연 판정의 최소 단위는 1ms다(`AGENTS.md`).
  - 0.5샘플(10.42µs)은 그 1%다.
  - ±100ppm의 시각 편향은 최댓값으로 다룬다. 실행 간 상쇄는 가정하지 않는다.
  - 채널 오프셋 자체 검증은 같은 ADC 시계의 두 채널을 쓰므로 ppm과 무관하며, 5a로 다룬다.
- **비교 보고(판정 아님):**
  - A2 대 A1: 정상 다중 경로 칸의 지연 산출 가능 비율 차이
  - A0 없음 대 A0: 1비트 손상 칸의 Ambiguous 비율
  - A4 진단
- **CI 통과와 실험 합격은 다르다.** 하네스는 기준을 단정하지 않고 수치만 내므로, 기준을 못 맞춰도 정상 종료한다. CI가 초록이어도 실험은 불합격일 수 있다. 실험 판정은 위 표의 수치로만 하며, 보고할 때 "CI 통과/실패"와 "기준 합격/불합격"을 따로 적는다.
- **채택:**
  - 1~9를 모두 충족하면 신호(A0 배치 포함)와 분석 기준을 동결한다.
  - 사용 가능 판정의 빈칸은 리그 자체 검증 뒤 채운다. 그 전까지 동결은 "합성 조건 한정"으로 표기한다.
- **실패:**
  - 기준을 바꾸지 않는다.
  - 원인을 (i) 동기·비트 구분 능력, (ii) 분류·매칭 규칙, (iii) 구현 결함, (iv) 시각 추정 편향으로 분류한다.
  - (i)이 원인이면 파형 재설계(A안)를 검토한다.
