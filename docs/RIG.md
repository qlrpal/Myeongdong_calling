# P0 측정 리그

목적: 앱 내부 타임스탬프와 무관한 **외부 종단 간 지연**을 재는 것. 기존 앱과 새 앱을 같은 기준으로 비교할 수 있는 유일한 판정 근거다.

## 1. 원리

수신 PC의 스테레오 라인 입력 하나에 L = 기준 신호, R = 수신 출력을 동시에 녹음한다. 두 채널이 같은 ADC 시계로 녹음되므로 **PC 간 시계 동기화가 필요 없다.** 마커별 L→R 시간차가 입→귀 지연(전기 출력 기준)이다.

## 2. 구성 (노트북 → PC 한 방향)

```
노트북 이어폰 출력 ──┬──→ 유선 이어폰 (노트북 내장 마이크 구멍에 밀착)   = 송신 입력
   (처프 재생)       └──→ PC 라인 입력 L                                  = 기준 신호

PC 이어폰 출력 ─────────→ PC 라인 입력 R                                  = 수신 출력
```

- 송신 입력은 **이어폰 → 내장 마이크로 소리를 넣는다.** 노트북 마이크 입력 단자에 전기 신호를 넣지 않으므로 마이크 바이어스, 감쇠, TRRS 결선 문제가 없다. (초기 안이던 마이크 단자 직접 주입은 직렬 저항으로 바이어스를 차단할 수 없다는 지적으로 폐기)
- 이어폰–마이크 거리 1cm ≈ 공기 전파 0.03ms. 테이프로 고정해 실행 간 거리가 바뀌지 않게 한다.
- **스피커는 쓰지 않는다.** 기준 신호는 전기에서 따므로 스피커 내부 지연(사용자 스피커는 지연이 큼)이 측정값에 그대로 더해진다. 유선 이어폰의 전기→음향 변환은 μs 수준으로 본다([추정], 측정하지 않음).
- 노트북에는 스테레오 라인 입력이 없어서 PC → 노트북 방향은 이 구성으로 측정할 수 없다.

### 필요한 것
| 품목 | 용도 |
|---|---|
| 3.5mm 1→2 분배 케이블 | 노트북 출력을 이어폰과 PC로 나눔 |
| L/R 분리 Y 케이블 (스테레오 수 1 ↔ 모노 2) | 두 신호를 PC 입력의 L, R에 따로 연결 |
| 3.5mm 수-수 케이블 2~3개 | 노트북–PC 거리만큼 |
| 유선 이어폰 | 송신 측 음향 주입 |

## 3. PC 설정

- Realtek 오디오 콘솔에서 후면 마이크 잭을 **라인 입력**으로 변경.
- Windows 녹음 장치 형식이 **2채널**로 열리는지 확인. 1채널만 되면 이 구성은 불가하고 2채널 USB 인터페이스가 필요하다.
- 같은 멀티탭 사용(접지 험 감소).
- 노트북 출력 볼륨은 PC 라인 입력이 클리핑되지 않는 수준(피크 −6 dBFS 이하).

## 4. 측정 세션마다 하는 자체 검증

1. **채널 오프셋:** 같은 신호를 L·R에 동시에 넣어 채널 간 시간차 측정(0 ± 서브샘플이어야 함).
2. **누화:** R 연결을 뺀 상태에서 R 채널 마커 검출 수가 0인지.
3. **클리핑:** L·R 피크가 −6 dBFS 이하인지.
4. **녹음 부하:** 수신 PC가 녹음기를 겸하므로, 녹음 켬 / 끔(앱 내부 기록으로 대조) / 동등 CPU 부하 대조를 한 번 수행해 영향을 기록.
5. **설정 고정:** 장치·드라이버·효과·MMCSS·전원 설정을 결과 파일에 기록.

## 5. 신호와 분석

- 단순 클릭 대신 **고유 코드가 들어간 대역 제한 처프**를 쓴다. 송신 노트북 내장 마이크 경로의 잡음 제거·AGC가 주기적 클릭을 잡음으로 지울 수 있고, Opus가 파형을 바꿔도 상호상관 피크가 유지되게 하기 위해서다. 처프 대역은 코덱 대역 안에 둔다.
- 검출: L에서 마커 위치, R에서 같은 코드의 상호상관 피크. 피크 품질이 임계값 미만이면 누락으로 처리(오검출 방지).
- 통계: 재시작이 상위 단위. 실행별 중앙값·P95·P99·보존율(R에서 검출된 마커 비율), 실행 간 분산.
- 노트북 마이크 경로의 잡음 제거·AGC 설정을 기록한다. AGC 적응은 실행 간 분산을 키울 수 있다.

## 6. 한계 (결과에 함께 표기)

- 출력은 전기 신호 기준이다. 이어폰 음향 발생 시각은 포함하지 않는다.
- 같은 코덱 루프백 하나로는 **출력 경로 단독 / 입력 경로 단독** 지연을 분리할 수 없다. 합계만 정확하다. 출력 설정 비교는 입력을 고정하고 합계 차이로 판정한다(E2).
- 수신 PC의 녹음 스트림 QPC로 앱 QPC와 대응시킬 수는 있지만, 그 대응에는 캡처 경로 지연이 미지의 오프셋으로 섞인다. 내부 분해용으로만 쓴다.
- 측정 방향은 노트북 → PC 하나뿐이다.
