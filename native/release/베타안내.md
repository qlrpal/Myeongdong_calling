# 베타 안내와 문제 제보

Windows x64용입니다. 운영체제는 [.NET10 지원 목록](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md)의 지원 범위를 따릅니다. 다른 Windows 버전에서의 이 앱 호환성 검증은 남아 있습니다. 실행 환경 포함 패키지는 .NET 별도 설치가 필요하지 않습니다.

현재 기본 Opus 48kHz 모노 10ms와 WASAPI 공유 출력, 직접 연결 우선·TURN 대체 경로를 사용합니다. 실험용 프레임/버퍼/공통 출력 선택과 음향·LAN 시험 도구는 이 베타 화면에서 제외했습니다. 통화 진단 저장·출력 재시작·앱의 미디어 인터페이스 선택은 유지합니다.

## 알려진 범위

- 베타의 실제 친구 환경·게임 부하·다른 회선·장시간 그룹 품질 검증은 남아 있습니다. 집 무선 구간에서 관측한 지연 스파이크도 앱 수정만으로 해결했다고 판단하지 않습니다.
- 자체 에코 제거가 없어 스피커 소리가 마이크로 들어갈 수 있습니다. 이어폰/헤드셋을 사용하세요.
- 키보드 단축키의 실제 게임 호환성, 장치 탈착/복구는 환경에 따라 후속 확인이 필요합니다.
- 화면의 RTT·큐·API 지연은 실제 입→귀 지연 측정값이 아닙니다.

## 문제가 생겼을 때

1. 발생 시각, 인원, 양쪽 증상, 재현 동작을 적습니다.
2. `연결 상세`에서 직접/TURN 경로와 오류를 확인합니다.
3. `상세 진단·고급 설정 → 진단 저장`으로 JSON을 저장합니다. 가능하면 양쪽 자료를 준비합니다.
4. 짧은 끊김은 `패킷 경로 기록 (30초)`을 양쪽에서 시작한 뒤 진단을 저장하면 분석에 도움이 됩니다. 녹음 기능은 아닙니다.
5. 출력 장치 오류는 장치를 확인하고 `출력 재시작`을 사용합니다. 정리 오류가 남으면 진단 저장 후 앱을 다시 시작합니다.

진단과 로컬 로그에는 IP·닉네임·장치 정보가 포함됩니다. 음성과 세션 토큰은 저장하지 않습니다. 원본을 공개 게시하기 전에 내용을 확인하세요. 로컬 로그는 `%LOCALAPPDATA%/MyeongdongCalling/logs/`에 있습니다.

`release-manifest.json`의 버전·SDK·파일 해시로 배포본을 식별할 수 있습니다. 이 목록은 서명이나 자동 업데이트 기능이 아닙니다.
