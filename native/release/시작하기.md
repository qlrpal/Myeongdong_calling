# 시작하기

1. ZIP 전체를 새 폴더에 풀고 `VoiceNative.exe`를 실행합니다.
2. 닉네임과 방 이름을 입력하고 `방 참가`를 누릅니다. `새 방 만들기`로 임의의 방 이름을 만들 수도 있습니다.
3. 친구에게 방 이름을 전달합니다. 같은 서버와 방 이름을 사용하면 연결됩니다. 최대 6명입니다.
4. `장치 설정`에서 마이크·출력을 고릅니다. 통화 중 바꾸면 같은 방에 재접속합니다. 저장한 장치가 없으면 다시 연결하거나 다른 장치를 직접 선택합니다.
5. 마이크 버튼으로 내 음소거를 전환합니다. 설정의 마이크 토글 단축키는 기본 꺼짐이며 통화 중에만 작동합니다. 다른 앱과 충돌하면 다른 조합을 선택합니다.
6. 상대 카드의 `볼륨`에서 그 사람의 소리를 조절합니다. `내 쪽 음소거`는 그 사람의 소리를 내 PC에서만 끕니다. 상대 마이크 상태는 최신 앱끼리 공유하며 오래된 정보는 미확인입니다.
7. `나가기`로 통화를 종료합니다.

기본 서버는 `https://qlrpal.ddns.net/`입니다. 방 이름은 문자·숫자·밑줄·하이픈 1~40자, 닉네임은 1~24자입니다. 방 이름을 아는 사람이 참가할 수 있으며 로그인·방 비밀번호·참가 승인 기능은 없습니다.

연결되지 않으면 서버 주소와 Windows의 앱 방화벽 허용 상태를 확인하세요. 공유기의 포트포워딩은 필요하지 않습니다.

설정은 `%LOCALAPPDATA%/MyeongdongCalling/settings.json`에 저장합니다. 업데이트는 새 폴더에 압축을 풀면 되고 기존 설정을 사용합니다. 게임·Windows의 기본 장치나 시스템 음량을 변경하지 않습니다.
