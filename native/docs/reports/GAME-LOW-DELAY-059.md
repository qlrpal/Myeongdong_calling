# 0.5.9 게임 부하 통화 시험

후속 [지속 발화·게임 공존 10분 시험](GAME-SPEECH-059.md)에서 발화 부하와 출력 안전 복귀 재현 여부를 확인했다.

2026-10-20 KST, 사용자가 Monster Hunter Wilds의 플레이 장면에 진입한 뒤 PC와 노트북에서 0.5.9 저지연 통화를 120초씩 실행했다. 양쪽 모두 정상 종료했다. 게임 설정과 장치 설정은 변경하지 않았다. 노트북의 DTS 효과는 원래 상태로 유지했다.

## 조건

- Opus LowDelay64, 48kHz 모노, 10ms 패킷, 내부 lookahead 2.5ms, 재생 목표 예비량 20ms.
- WASAPI 공유/이벤트 출력, RAW 우선, 제한 공급 및 안전 복귀 사용.
- 미디어 소켓에 LAN 주소를 지정한 직접 연결. 외부망이나 TURN 시험은 아니다.
- PC 게임 프로세스 PID 22880의 CPU 누적 시간이 시험 중 405.36 → 555.41 → 721.05초로 증가했다. 게임은 종료하지 않았다. GPU 부하·프레임률·청감은 측정하지 않았다.
- 마이크를 사용했지만 원음과 통화 음성은 저장하지 않았다. 합성 측정 신호는 사용하지 않았다.

## 결과

수치는 종료 직전 진단의 누적값이다. 각 기기의 독립된 120초 구간이므로 양쪽 패킷 수를 단순히 빼서 손실로 해석하지 않는다.

| 항목 | PC 수신 | 노트북 수신 |
|---|---:|---:|
| 실행 오류 / 출력 장치 오류 |없음 |없음 |
| 버퍼 부족 |0ms |0ms |
| 재버퍼 |0회 |0회 |
| PLC 보완 합계 |90ms |30ms |
| 최대 연속 PLC |40ms |10ms |
| 늦은 패킷 |5개 |0개 |
| 복구를 위한 음성 폐기 |0ms |0ms |
| 송신 큐 폐기 |0프레임 |0프레임 |
| 송신 큐 최대 대기 |4.66ms |2.21ms |
| 출력 재시작 |0회 |0회 |
| 출력 안전 복귀 |0회 |1회 |
| 최종 출력 공급 목표 |15.17ms |22ms |
| 관측 수신 간격 최대 |63.80ms |52.28ms |

PC는 제한 공급을 유지했다. 노트북은 첫 진단 후 약31초에 출력 안전 복귀가 관측됐으며 이후 전체 출력 용량 22ms로 동작했다. RAW는 양쪽 모두 활성 상태였다. 버퍼 부족이 없더라도 PLC와 출력 복귀가 있으므로 무결점 통화로 표현하지 않는다.

첫 5개 진단을 제외한 약1초 간격 표본에서 수신 큐 최소/중앙/최대는 PC 9.67/30.83/48.33ms, 노트북 15.02/36.08/72.25ms였다. 마지막 큐는 각각22.35/26.00ms였다. 이 표본에서는 큐가 계속 누적되지는 않았다. 모든 순간의 상한이나 장시간 안정성을 입증한 값은 아니다.

## 남은 항목과 해석 한계

PC 입력 불연속은 첫 진단과 마지막 모두1회로 추가 증가가 없었다. 노트북은6 → 9회로3회 증가했고 약23초와101초 진단에서 변화가 관측됐다. 입력 시각 오류는 양쪽0이었다. 입력 콜백 간격 최대 관측값은 PC18.42ms, 노트북25.54ms였다. 약1초 간격 진단만으로 입력 불연속·PLC·출력 복귀의 정확한 선후나 공통 원인을 확정할 수 없다.

마이크 RMS가 대부분 매우 낮았고 마지막 표본은 양쪽 -120dBFS였다. 따라서 이번 결과는 게임 실행 중 오디오 경로의 진행·큐 안정성 확인이며, 지속 발화의 코덱 부하와 음질을 검증한 시험은 아니다. 사용자 귀에 들리는 끊김이나 전체 입→귀 지연도 직접 측정하지 않았다. 기존 DTS 원인 시험과 이번 결과를 합쳐 일정한 전체 지연 수치로 제시하지 않는다.

현재 기본값을 유지한다. 다음에는 지속 음성 입력을 포함한 더 긴 게임 공존 시험으로 노트북 입력 불연속과 출력 안전 복귀의 재현성을 확인한다. 안전 복귀를 제거하거나 예비 버퍼를 일괄 확대하는 변경은 이번 결과로 정당화되지 않는다. 이후 실제 외부망에서 직접 연결과 TURN 경로를 각각 검증한다.

## 재현과 정리

양쪽에서 같은 방 이름과 각자의 LAN 주소로 실행했다.

```powershell
TransportProbe.exe --bound-lowdelay-soak SERVER ROOM OUTPUT.json pc PC_LAN_IPV4
TransportProbe.exe --bound-lowdelay-soak SERVER ROOM OUTPUT.json laptop LAPTOP_LAN_IPV4
```

원본과 분석 코드는 Git 제외 경로 `native/.local/game-codec-059/`에 보관했다. 양쪽 시험 프로세스 잔류0을 확인했다. 제품 코드는 변경하지 않았으므로 기존 전체 검사를 반복하지 않았다.
