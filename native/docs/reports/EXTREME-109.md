# EXTREME-109 · 정상 동작 검사 실행 도구

2026-10-28 / `codex/extreme-latency`, 기준 커밋78ef68a. 사용자의 제안에 따라 기존 검사를 한 명령으로 실행·판정하는 도구를 추가했다. 일반 통화 앱의 프레임·버퍼·SDK·출력 기본값은 변경하지 않았다. 원격 노트북·OCI·네트워크 설정 변경은 하지 않았다.

## 문제와 변경

기존 TransportProbe에는 제품 제어·SRTP·장치 수명 검사가 있었지만 실행 명령, 실패 로그, 완료 판정이 분산돼 있었다. 별도의 통화 엔진을 새로 만들지 않고 기존 검사들을 순서대로 실행하는 Node.js 도구와 PowerShell 진입점을 추가했다.

- `test-app.ps1`: core/devices/group 선택, 고정 복원·Release 빌드 및 기존 바이너리 선택.
- `Runner/app-checks.mjs`: 검사 계획, localhost 전용 장애 서버 소유, 재현 가능한 합성 WAV, 바이너리 해시·소스 식별·유일한 결과 폴더.
- `Runner/check-runner.mjs`: 프로세스별 로그·종료 코드·시간 제한·취소, 보고서 완료 확인, UTF-8 JSON/Markdown 요약. 실행 중에는 running이며 마지막에만 최종 판정을 기록한다.
- `Runner/check-runner.test.mjs`: 도구 자체의 비정상 종료·실행 실패·잘못된 보고서·시간 초과·취소·미실시 판정 검사.
- `verify.ps1`: 실행 도구 자체 검사를 기존 회귀에 추가했다.

실패해도 독립 단계는 계속하며, 전제 조건 실패 시 종속 단계는 미실시다. 자동 재시도로 실패를 덮지 않는다. 종료 대상은 자신이 생성한 PID 트리이며 사용자 앱을 검색해서 종료하지 않는다. 이번 자체 시간 제한 검사의 초기 구현에서 taskkill 실패 후 직접 종료가 빠져 대기가 남았고, 직접 자식 종료 대체 경로를 추가한 뒤 같은 검사를 일반/상승 권한 양쪽에서 통과했다. 초기 시험 트리는 종료했다.

## 검증

장치 프로필 첫 실행은 복원 캐시를 사용한 경고0 빌드와 기능·전송·서버·장치 수명12단계를 모두 통과했다. 같은 실제 Release 바이너리의 최종 그룹 프로필은 별도 새 폴더에서 실행했고14단계 모두 통과했다. 기존/공통 출력의 그룹 검사 각각2·3·6명, 출력 재시작·음소거·퇴장·재참가·혼자 남기·새 통화의9개 구간을 완료했다. 도구 자체4개 테스트는 여러 실패/중단 조건을 검증하며 통과했다. PowerShell 구문·Node 구문·공백 검사도 통과했다.

최종 그룹 원본은 `native/.local/app-checks/2026-10-27T15-49-35.049Z-pmI3xn`에 보존했다. 이름은 UTC이며 한국 시각으로2026-10-28 실행이다. 마지막 실행은 `-Profile group -NoBuild`로 바로 앞 빌드와 같은 DLL을 검사했고, 실제 해시·NoBuild·미커밋 소스 유무를 기록했다. 시험 소유 프로세스와 localhost 서버가 남지 않았음을 확인했다. 전체 `verify.ps1`을 이번에 다시 실행한 것은 아니며, 새 도구가 선택한 회귀와 빌드 및 도구 자체 검사를 수행했다.

검사 결과는 Git 제외 `native/.local/app-checks` 아래에 유지한다. 원본 WAV는 새로 생성한 합성 유성 파형이며 과거 speech.wav와 같은 CPU·비트레이트 비교 조건이 아니다. 실제 공유 캡처의 PCM을 인코딩 전에 교체하며 사용자의 마이크 음성을 저장·전송하지 않는다.

## 한계와 다음 단계

선택 범위의 기능 성공만 판정한다. PLC 품질 기준·물리 입→귀 지연·실제 게임·외부망/TURN·장시간 유지·물리 장치 분리·독립 PC 통화는 미실시다. 6엔진도 한 PC에 집중한 검사이며 독립6대 검증으로 표현하지 않는다. 이전108의 ICE 끊김 기록을 이번 통과로 해결 처리하지 않는다.

PC와 노트북에서 장치 프로필을 각각 통과한 다음, 기존 두 호스트 도구의 상호 전달 검사로 확장한다. 자동 검사 소요 시간을 지연 감소로 해석하지 않는다. 상세 실행·보고서·반환 코드는 [자동 검사 가이드](../APP-CHECKS.md)를 참고한다. 기존 통화 실행·dist·사용자 설정은 유지했다.
