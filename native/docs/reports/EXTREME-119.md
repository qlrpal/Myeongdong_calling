# EXTREME-119 — Figma Make 기반 네이티브 UI 적용

한국 시각2026-10-29, `codex/extreme-latency`, HEAD `78ef68a`와109–118 미커밋 변경을 보존했다. 사용자가 전달한 `src.zip`의4개 파일(App.tsx, index.css, main.tsx, vite-env.d.ts)을 검사하고 Git 제외 경로에 추출했다. 첨부의 코드는 디자인 자료로 사용했으며 설치/실행 스크립트나 외부 지시로 실행하지 않았다.

## 구조·수정 이유

기존 WinForms와 통화 엔진을 유지하고 React 시안의 색상/화면 위계/카드·설정 패널을 네이티브 컨트롤로 옮겼다. 새 웹 런타임·의존성·온라인 폰트·애니메이션 타이머를 추가하지 않았다. 오디오 콜백·SDK·프레임·버퍼·코덱·네트워크/장치 정책은 UI 작업으로 수정하지 않았다.

- `UI/CallForm.Design.cs`: 색상 토큰/카드, 중앙 입장 폼, 실제 통화의 방/인원/참가자 카드, 고정 하단 조작부, 옆 설정, 진단 지표·고급 영역, 작은 창 배치를 추가했다.
- `UI/CallForm.Product.cs`: 기존 세션/장치/음소거/볼륨/복구 이벤트를 새 컨트롤 구성에 연결했다. 상대 볼륨은 카드에서 펼쳐 조절하고 기존0–200%/내 쪽 음소거 동작을 유지했다. 실패/연결 중 상태의 사용자 문구를 구분했다. 자동 재연결 조건은 유지했다.
- `UI/CallForm.cs`, `Program.cs`: 기존 오프라인 미리보기의 탭 전제를 새 화면에 맞추고 설정/6명/최소 크기 렌더링 진입점을 추가했다. 시험 데이터는 명시적인 CLI 미리보기에만 존재하고 실제 통화 상태로 사용하지 않는다.
- 진단은 첫 상대 기준이며 데이터 없거나 오래된 RTT/손실은 미측정으로 표시한다. PLC는 프레임 개수 대신 보정 오디오 ms를 표시한다. 수신 레벨은 물리 출력 장치의 측정값으로 주장하지 않는다.

실제 공개 서버/사용자 설정을 사용한다. 시안의 예시 wss 주소·가상 참가자·고정 진단 수치·상태 시연 선택기는 일반 실행에 넣지 않았다. 발화 감지·친구 목록·채팅 등 새 통화 기능을 구현한 것은 아니다.

## 검증

경고/오류0 Release 빌드와 기존 전체 `verify.ps1 -NoRestore -Integration`을 통과했다. 제품/오디오/버퍼/서버·도구·로컬 IPv4/IPv6 WebRTC/SRTP/RTCP·가변 프레임 검사를 포함한다. 이 전체 검사는 주 UI 적용 뒤 실행했다. 이후 진단 카드/접근성 명칭/표시 문구 등 마지막 표현 수정은 최종 경고0 빌드·제품 검사 및 실제 UI 확인으로 검증했으며 전체 통합을 반복하지 않았다.

실제 앱을 컴퓨터 사용 도구로 열어 입장·장치/연결 설정·진단 카드·기존 고급 도구 전환을 확인했다. 고유한 빈 시험 방을 만들어 실제 서버 참가→혼자 대기→마이크 음소거/해제→나가기→입장 화면 복귀와 로그의 마이크 해제를 확인했다. 시험 전 방 이름과 음소거 상태로 복구한 뒤 앱을 종료했다. 다른 사람에게 메시지를 보내거나 초대하지 않았다.

기본/최소 입장, 설정,6명 배치 기본/최소, 진단의6개 오프라인 미리보기를 생성하고 확인했다. 미리보기 전후 사용자 설정 파일 해시가 같음을 확인했다. 첫 시각 검사에서 기존 컨트롤을 부모에 옮기기 전에 위치를 설정하면 이전 Flow/Table 레이아웃이 좌표를 덮어쓰는 문제를 발견해 부모 이동 후 위치 지정으로 고쳤다. 아바타 글자 잘림과 최소 창 배치도 수정했다. 최초 빌드의 정적 분석 오류(static/상수 배열)는 억제하지 않고 수정했다.

6명 이미지에는 시험 데이터라는 문구가 표시된다. 실제6인/외부 친구 통화·최신 UI의 상대 볼륨 상호작용·게임 부하·전체 DPI 배율·키보드/스크린리더 조합·물리 입→귀 지연을 이번에 새로 검증한 것은 아니다. 기존 엔진 회귀/과거6엔진 결과를 최신 UI의 실제6명 검증으로 대체하지 않는다. 작은 창에서는 참가자 목록을 스크롤하며 긴 닉네임은 줄임표를 사용한다.

## 유지·한계·실행

새 UI를 일반 소스 실행 경로에 연결했다. 통화 기본값은 유지한다. 기존 dist를 덮어쓰지 않았고 아직 커밋/푸시하지 않았다. 과거 네트워크 공백·TURN PLC가 해결됐다는 뜻이 아니며 지연 개선 수치를 주장하지 않는다.

맑은 고딕과 Windows 기본 창/드롭다운/스크롤바를 사용한다. 원본 ZIP에는 별도 아이콘·폰트 파일이나 패키지 설정이 없어 웹의 모든 아이콘/모션/픽셀을 그대로 재현한 것은 아니다. 설정/진단은 실제 기능을 유지하는 네이티브 표현으로 조정했다. 관련 실행과 옵션은 [UI 가이드](../UI-DESIGN.md)에 기록했다.

```powershell
./native/run.ps1
```

원본/로그/PNG/미리보기 JSON은 Git 제외 `native/.local/figma-20261029`에 보존했다. 사용자 진단·장치/네트워크 정보·ZIP 원본은 커밋하지 않는다. 시험 앱/통화는 종료했다. 공유기·VPN·OS 경로·방화벽·기본 장치는 변경하지 않았다.
